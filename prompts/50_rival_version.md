# 対抗案（別の制作チームの作品）をつくる

依頼者の言葉：「1案だけだと比較できないから、別の動画編集チームの作品も作ってほしい。…さっきのクオリティに負けないようなやつを頼む」。
実例：reference/teamB/（concept.md が監督からの指示、content.md・editing.md が計画、qc_B1.3.md が QC）。

---

```
同じ素材で、今の案（A案）とは意図して違う対抗案（B案）を、同じ品質基準で作ってください。作業は別のブランチ（またはフォルダ teamB/）で行い、A案のファイルは変えないでください。

1. コンセプトを一言で決める（例：「地面に“住所”をつける」）。A案との違いを5つ先に決め、崩さない：
   入り方（例：コールドオープンと問い）／画づくり（例：シネスコの帯）／図解のしかた（例：実写の上に直接描く・分割画面）／語り（例：ナレ5割、問い→答え）／締め（例：帰り道でできること）
2. 守る基準は A案と同じ：docs/01・04・05・07、事実確認（reference/research/）。このパートは部門の1作業（会社全体の意味は背負わない）。
3. 内容計画と編集計画を別々に（templates/）。曲も A案と違うものを選び、規約を確かめて台帳に書く。
4. 書き出し → 自動QC → 独立レビュー → 直す、を A案と同じだけ回す。「A案に負けない」品質にする。
5. 最後に、両案を並べて見せる資料（同じ秒の並べたシート、尺・ナレの量・実写の割合・QC の結果の表）を作り、依頼者に選んでもらう。
```

## 比べた後にすること

- 選ばれた案の「何が効いたか」を言葉にする（playbook/30_case_study.md §4 の形）。依頼者が理由を言わなければ、推測であることを書いて記録する。
- 負けた案から取り入れるもの・取り入れないものを、理由つきで決める。
