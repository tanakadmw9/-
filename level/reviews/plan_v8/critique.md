**芯「海からの高さ」は覆さない。**見るのは、この芯で、家族に正しく、上手く伝わる計画になっているか。

## 先に結論

**芯は強い。**
- 「高さの0は海」は、子どもが人に言いたくなる本当の話。
- 1本目（位置の目印）との対もきれいで、声の専門用語も「水準測量」1つに絞れている。
- 拍の表と同期点は、秒まで全部そろっている。

**ただし、このまま出すと「また違う」と言われる所が3つある。**
1. **最初の20秒と終わりの10秒が v7 と同じ画。**
   - 0–20.2 秒は v7 と、素材の秒・窓・曲・8小節の止め・止め絵 K 7.82・ラベル「標尺」まで同じ。
   - B8・B12・終わりの画も v7 と同じ。
   - 依頼者は v7 の絵コンテ p1 を見たばかり。v8 の p1 はほぼ同じページになる。
2. **看板の約13秒が「日本の高さのしくみ」で、家族の仕事が脇役になる。**
   - 持ち帰る言葉3（家族の仕事）には絵がない。
   - 子どもの帰り道の一言（content §1）にも、家族の仕事が入っていない。
3. **「問い → 曲が止まる → 答えは、海 → 鉄琴」はクイズの型。**
   - v5 で却下されたクイズ（クイズの間は曲が止まり、現場の音だけ）と同じ仕掛け。
   - しかも「海は遠いので」は、海の近くに住む家族の実感と合わない。素材の地域は海から遠くない。

**事実で測量士が止める所が4つある。**
- ◎の N4 から「東京湾」が抜けている。
- □ が 0 から順に灯るので、「今も海から運んでいる」と見える。
- 国の水準点と、家族がつくる新しい目印が、同じ紺の □・同じ言葉になる。
- この現場の作業によって、締めの「海からの高さ」が成り立たないことがある。

**点は 16/20。**
- 下の §4「出す前に必ず」の7つを直せば 19。
- 撮り足し（標尺手の顔、目印の実物）が来れば 20。

## 3. 依頼者がまた「違う」と言うとしたら（強い順）

1. **「前と同じ動画に見える。少し変えて使い回してない？」**
   - 依頼者が v7 を断った言葉（「今の考えに固執して、勿体ないから少し変えて使おうとしてない？」）が、そのまま当てはまる。
   - 最初の20秒は、曲の止めと止め絵まで v7 と同じ。B8・B12・終わりの画も同じ。
   - 依頼者は最初の数ページで判断する。p1 は v7 の p1 とほぼ同じページ。
   - → E1 の①②③。表で正直に出して、変えた所を先に見せる。素材の都合でない終わりの画は変える。
2. **「国の高さのしくみの話になって、家族の仕事が見えない」**
   - 1本目で依頼者が直させたのは「背負いすぎ」だった。看板の約13秒が日本地図。
   - 家族の仕事（言葉3）は、絵のない「つないで」だけ。
   - → P1、E3（線と新しい □ を B10 に移し、「こうしてできた」に画を持たせる）、E6（道路の線）。
3. **「クイズっぽい／また海や水の話？」**
   - 「でも…でしょう。（止め）答えは、海。（チン）」は、v5 の却下されたクイズの間と同じ。
   - さらに「海は遠いので」は、海の近くに住む家族の実感とずれる。
   - → E4（「答えは、」を外す）、P2（「東京湾は遠いので」）。
   - 海は真上の地図の色だけで、水面・深さ・波は描かない（content のとおり。守れている）。
