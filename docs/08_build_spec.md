# 08 制作仕様（アニマティック v4.1 用・部品の作り方）

制作の分担のための仕様書。設計の根拠は docs/01〜07。ここは「どう作るか」の約束だけを書く。

## 1. 仕組み

- 正本：`comp/timeline.json`（`scripts/20_plan_timeline.py` が生成。v4.5 からは24小節の格子に置く。v4.1 の頃は仮ナレの長さから並べていた）。**手で直さない**。
- `comp/index.html` は `scripts/21_build_index.py` が生成。**手で直さない**。
- 各場面は `comp/compositions/<id>.html` の sub-composition。タイミングは**すべて変数 `cues`（JSON文字列、場面頭からの秒）**で受け取り、ハードコードしない。ナレが差し替わると cues の数値だけが変わる。
- 場面の長さは変数 `dur`（秒）。場面は `dur` が多少変わっても破綻しないこと（最後の状態で止まって待つ）。
- 1場面だけの確認：`python3 scripts/21_build_index.py --scene <id>` → `dev/<id>/` ができる（assets 等は comp/ へのリンク。実写の上に乗る場面は下の実写も敷かれる）。
  - Chromium の場所は `source scripts/lib_env.sh` が探す（見つからなければ `HYPERFRAMES_BROWSER_PATH` を指定）
  - `npx hyperframes lint dev/<id>` → `npx hyperframes check dev/<id> --json` → `npx hyperframes snapshot dev/<id> --at 0.5,1.2,...`（PNG を Read で見る）
- HyperFrames の書き方：`node_modules/hyperframes/dist/skills/hyperframes/SKILL.md` と `references/format.md`、`references/motion.md`。

## 2. 場面ファイルの約束（守らないと書き出しが壊れる）

- 雛形：`comp/compositions/telop_keyword.html`（部品の見本）。
- `<html data-composition-variables='[...]'>` に `cues`（string）・`dur`（number）と場面固有の変数を宣言し、**default には今の timeline.json の値**を入れる。
- 中身はすべて `<template>` の中。ルートは `<div id="root" data-composition-id="<id>" data-width="1920" data-height="1080">`、CSS は `#root { position:absolute; inset:0; }`。
- タイムラインは1本、`gsap.timeline({ paused: true })`、最後に `window.__timelines["<id>"] = tl;`。
- `window.__hyperframes.getVariables()` で `cues` を読み `JSON.parse`。
- 要素 id は場面 id を頭につける（`#d2-arc` など）。ページ全体で一意。
- `fromTo` を使う（`from` は禁止）。`Math.random`・`Date`・タイマー・`repeat:-1` 禁止。
- `.clip` 要素に transform/visibility を tween しない（子要素を動かす）。CSS の transform と GSAP の transform を同じ要素に混ぜない。
- 画像パスは `assets/...`（ルート相対）。
- GSAP・フォント・tokens.css は index 側で読み込み済み。場面で `@font-face` や `<script src>` は書かない。
- SVG は 1920×1080 の viewBox でインライン。線は `stroke-dasharray/dashoffset` の tween で「描く」。
- テキストは HTML 要素で（SVG text より check が効く）。

## 3. 見た目の約束（docs/04 の要約。迷ったら docs/04）

- 色は tokens.css の変数だけ：`--ink --navy --paper --grid --orange --orange-dark --white --sub --plate`。**既知・基準＝紺、はかる・新しい＝オレンジ**。オレンジは図形専用（紙の上の文字は `--orange-dark` を大きい字だけ）。赤×緑で意味を伝えない。グラデ・影・光沢は使わない（光の線のごく弱い発光だけ可）。
- 書体：`var(--font-ja)`（BIZ UDPゴシック 400/700）、数字は `var(--font-num)`。`font-feature-settings:"palt"`。
- 文字サイズ：章タイトル 104〜120px、キーワード 64〜72、ラベル主 44〜52 Bold、補足 34〜38 Regular。**34px未満禁止**。1行16字まで・2行まで。
- タイトルセーフ：左右96px・上下54pxの内側。
- 図解の記号：既知点＝紺の△（中心に点）、新しい点＝オレンジの◎、光の線＝オレンジ5px（丸い端）、角度＝オレンジの弧、設計線＝紺の点線、線幅4〜6px。方眼は `--grid` の細線（1px、80px間隔くらい）。
- 実写の上の文字は紺88%の板（`--plate`、角丸6px）に白字。対象ラベル＝対象の上の点（直径10px）→白の引き出し線2px→板。
- 動き：入り 0.4〜0.6秒 `power3.out`（フェード＋16〜24px持ち上がり、またはマスク）、出 0.25〜0.35秒 `power2.in`、移動 `power2.inOut`。**バウンス・エラスティック禁止**。**同時に動くのは1か所**（重ねるなら0.1〜0.2秒ずらす）。タイプライター禁止（数字のカウントアップは可）。点滅は1秒3回まで。
- 言葉と絵は ±0.3秒以内：cue の時刻に、その言葉の絵が**出始める**ようにする。
- 汎用アイコン・絵文字・ストック風イラスト禁止。線画は図解の記号と同じ線の言語で。

## 4. 場面ごとの仕様

座標は 1920×1080。cue 名は timeline.json の `cues` のキー。

### title（実写 S04 の上に乗る。透明背景）
- 変数：`target_x=820, target_y=268`（S04 のプリズム中心）。
- `reticle_in`：照準（細い十字線＋円＋目盛り、白2px。明るい空でも見えるよう、線の外側にごく薄い紺の縁取り1px可）がプリズム付近の少しずれた位置から現れ、`power2.inOut` で target に寄る。
- `lock`：照準が target に合い、中心の点がオレンジに点る（ここで効果音「ピッ」とBGM開始）。照準はその後そのまま残す。
- `title_in`：右下に章タイトル「基準点測量」（112px Bold 白）。その上に小さく分野名「測量」（36px、`--sub`）。文字の下に、下端からの紺のグラデーション（最小限の不透明度。docs/04 §5 で許可されている唯一のグラデ）。人物（左）とプリズム（中央）に重ねない：x ≥ 1060、y 760〜980 の範囲。
- `sub_in`：サブタイトル「まちづくりの“最初の一点”」（52px Bold 白）。
- `out`：照準と文字が 0.3秒で消える（`power2.in`）。

### d0_marker（紙の背景・全面）
- 目的：物語の主役「基準点の標識」の形を一度見せ、用語「基準点」を仕組みの前に紹介する。機械はこの点の真上に据える、まで見せる。
- 左半分（中心 x≈620）：地面の線（`--ink` 4px）と、地面に埋まった金属標（真横から少し見下ろした楕円の円盤、紺の輪郭、中央に十字と点）。地面の下に標石（四角い柱）を紺の細線で描いてよい。`marker_in` で標識が現れ、中心の点がオレンジに1回だけ灯って紺に戻る。
- `tripod_in`：三脚（紺の線画）が上から下りてきて標識をまたいで立ち、三脚の頭から標識の中心へ紺の点線（求心＝真上に合わせる）が下りる。
- `term_in`：右側（x 1040〜1800）に用語カード：「基準点」（72px Bold `--ink`）、その下に「位置の“ものさし”になる目印」（48px Regular `--ink`）。左にオレンジの縦線6px。
- `out` 以降は最後の状態で止まる（次はカット）。

### d1_observe（全面。S09 の静止画を内蔵）
- 変数：`ts_x=613, ts_y=572`（TS の望遠鏡）、`prism_x=1446, prism_y=137`（プリズム）。
- 画像：`assets/video/S09_freeze.png`（色あり）を全面に敷き、`desat` から 0.6秒で `assets/video/S09_freeze_desat.png` をフェードイン（CSS filter は使わない）。
- `ts_label`：TS の上に点→引き出し線→板「トータルステーション」（48px Bold 白）＋「角度と距離をはかる機械」（36px `--sub`）。板は x 900〜1500, y 600〜760 付近（草の上）。人の顔（左上）に重ねない。
- `prism_label`：プリズムの上に点→下へ引き出し線（2人の人物の間を通す）→板「プリズム」＋「光をはね返す鏡」。板は y 400〜540、x 1250〜1800 付近。人物（x 1230〜1340 と 1560〜1650、y 100〜340）に重ねない。
- `angle`：TS からプリズムへオレンジの線（5px）が 0.6秒でのびる（＝向き・角度）。TS の位置に小さなオレンジの弧を添えてよい。
- `distance`：光の粒が TS→プリズム→TS を 0.5秒ずつで往復（測距）。
- `to_paper`：0.3秒でラベルが消え、0.7秒で写真が紙（`--paper`）に溶ける。TS の位置は紺の△、プリズムの位置はオレンジの◎ に置き換わり、オレンジの線だけが残る（次の d2 は紙の上から始まる）。

### d2_topview（紙・全面）— しくみの核心。最もゆっくり、丁寧に
- 配置：既知点 A（紺△）(560, 760)、もう一つの既知点 B（紺△）(470, 260)、新しい点 P（オレンジ◎）(1380, 520)。
- `setup`：方眼が薄く現れ、A、つづいて B が現れる。A→B に紺の点線。B の横に「もう一つのわかっている点」（36px、`--navy`）。
- `known`：A の横に「わかっている点」（48px Bold `--navy`）。A がゆっくり1回だけ強調（拡大1.15→1）。A の上に真上から見たTS（小さな円＋十字、紺）。
- `angle`：A を中心に、AB の向きから AP の向きへ線が回り、オレンジの弧がのびる（0.8秒）。弧の近くに「角度」（52px Bold `--orange-dark`）。
- `distance`：A から P の方向へオレンジの線（5px）がのびる（0.8秒）。線の中ほどに「距離」（52px Bold `--orange-dark`）。
- `new_point`：線の先にオレンジの◎が現れる。「新しい点」（48px Bold `--orange-dark`）。
- `fix`：座標の数字が P の近くでカウントして止まる（`var(--font-num)` 40px `--ink`：「X 1234.567 m」「Y 2345.678 m」、0.7秒で止まる。止まる瞬間＝`fix`）。下に「（数値は例）」34px。ここで効果音クリック。
- 以降は止まって待つ。

> **d3_traverse・d4_bridge・d5_everyday は v4.5 の構成Aで廃止**（部品は reference/history/obsolete/）。いまの場面は chapter_door・title・d0_marker・d1_observe・d2_topview・map_link・endcard（comp/timeline.json の scenes）。

### d3_traverse（紙・全面）
- 冒頭：d2 の A・B・P を同じ位置で描いた状態から、0.9秒で全体を縮小（0.55倍、中心を左寄りに）して視野を広げる。座標表示やラベルは描かない（すっきり）。
- `chain`：P→Q→R→S とオレンジの線と◎がリズムよく（0.35秒おき）つながる（右方向へ）。
- `last`：最後の点から、右端の別の既知点 C（紺△）へ線がのびる。計算で求めた位置（オレンジの小さな点）と C を、拡大の丸窓（紺の円）で比べる。丸窓の中で 2つがほぼ重なる。横に「ずれを確認」（48px Bold `--ink`）。
- `check`：紺の✓が現れる（効果音クリック）。0.3秒後、オレンジだった点がすべて紺に変わる（＝新しい基準点になった）。【要監修：ずれを「無理に合わせる」ように見えないこと】
- 以降は止まって待つ。

### d4_bridge（紙・全面）— 観客自身の発見
- `network`：さらに引いた地図。基準点（紺△、小さめ）が中心から外へ波のように広がって網になる（0.9秒、点は12〜16個）。中央を斜めに横切る川（`--grid` の帯＋紺の細い岸線）と「川」（44px Bold `--ink`）。
- `road`：網の点をたどるように、道路の設計線（紺の点線6px）が左から右へ引かれ、川を横切る。
- `banks`：川の両岸から、橋（`--ink` の太い帯）が中央へ向かって同時にのび始める。
- `middle`：橋の先が中央の手前で止まる（すき間が残る）。
- `pause`：すべて静止（ここで BGM が抜ける。問いの「間」）。何も動かさない。
- `same_point`：両側の橋の先から、**同じ一つの基準点**（網の中の紺△を1つ強調、オレンジの輪）へオレンジの線が結ばれて光る。「同じ基準点」（52px Bold `--ink`）。
- `join`：橋のすき間が閉じて、1本につながる（効果音「カチッ」）。
- 以降は止まって待つ。

### d5_everyday（紙・全面）
- `life_in`：d4 の道路と橋が、そのまま暮らしの線画になる：家並み・木（線画、紺とインクの線だけ）が道路の両側に描かれ、道路は実線の道に変わる。
- `road_glow`：道路がゆっくり一度だけ明るくなり（オレンジの細い縁取り）、車1台（簡単な線画）が橋を渡って動き出す（同時に動くのはこれだけ）。
- 最後に、道路わきの小さな紺△（基準点）が一度だけ強調される（＝「ここから始まっています」）。
- 図形は全部「図解の記号と同じ線の言語」で。可愛らしいキャラクター・アイコン素材は使わない。

### endcard（S10 の最後のコマの静止画の上）
- 背景：`assets/video/S10_last.png` を全面に敷く（意図的な静止）。下からの紺のグラデーションで文字を守る。
- `reticle`：画面中央付近（960, 640）に照準が現れる。
- `point`：照準が縮んで消え、オレンジの点が一つ残る（＝最初の一点に戻る）。
- `text_in`：章タイトルと同じ配置ルールで締めの一文「まちづくりの“最初の一点”」（88px Bold 白）、その上に小さく「基準点測量」（36px `--sub`）。
- `fade`：全体が 0.8秒で黒へ。

## 5. 音（担当：音響）

- 層：VO（`audio/vo_temp/*.wav`）、SE（4〜5種、合成）、AMB（環境音、合成）、BGM（`audio/bgm/` に人間が置いた曲。無ければ仮BGM）。
- 配置とキーフレームは timeline.json の `vo` `se` `bgm` `amb` から。スクリプト `scripts/30_mix.py` が stems と mix を作り、`comp/assets/audio/mix.wav` に置く。
- レベル：BGM はナレ中ナレより15〜18dB下、ナレ無し6〜8dB下、下げ始めはナレ開始0.3〜0.5秒前。環境音はナレより約20dB下、図解区間はさらに下げる。SEはナレより大きくしない。切れ目すべてに10ms以上のフェード。完成 −24 LUFS ±1、True Peak −2 dBTP以下、48kHz ステレオ。
