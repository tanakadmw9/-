## 1. 批評への対応

| 指摘 | 対応 |
|---|---|
| 「どこまでもまっすぐ」は誤り（読める距離に限りがある）。B7 で機械を動かす理由とも食い違う | N4「この機械でのぞくと、目線が、ぴったり水平な線になります。」。N7「線がとどくのは、目で読める所まで。だから機械を前へ移して、高さを次の点へつなぎます。」【要監修：言い方】 |
| いちばんの「えっ」が声にない／B5 に入らない | N5b を「目盛りが大きいほうが、低いんです。」にし、B5 を4小節（12–15）、B6 を2小節に。決めの文字は約4秒出す。標尺の足元が 0 であることを先に見せる |
| オレンジの実線＋電子音は「光の線」に見える（前のパートの TS と同じ） | 目線は**オレンジの点線**で、接眼レンズから伸ばす。音は電子音にしない（木琴の小さな場面転換音を低く）。「ピッ」は照準の2か所だけ |
| 図が現場のやり方と違う | 機械は2本の標尺のちょうど中間（左右に同じ長さの矢印）。後ろの標尺は水準点の上、前は標尺台の上。B7 は機械が前へ → 後ろの標尺が追い越して次の点へ【要監修】 |
| N の寄りを3回、元の秒が重なる。人ごと縮む | 看板の静止は人が離れたレベルだけのコマ（N 12.75 秒、タイトルと同じ角度＝主役が戻る）。B4 は N 2.5–4.4 秒、B6 は N 7.8–10.3 秒で重ならない |
| S の秒のずれ、N3 が9小節頭にかぶる | S 51.0–55（載せる）、遠くの標尺の人を B2 の終わりへ、N3 は 15.6 秒から 19.4 秒で終わる |
| 往復を書く手元の上で言う | N6「読んだ数字を書きとめ、行きと帰りで確かめます。」（3.6 秒）。B7 の終わりに戻る矢印を描く案は、残り 0.3 秒で読めないので外した |
| 締めの 480p に寄る | 寄りは毎秒0.4%（止まって見えないためだけ） |

採らなかった指摘：なし（別の中心の絵「海からはかる」は §3 で依頼者に聞く）。

## 3. この計画の弱点（v2 自身）

| # | 弱点 | いまの手当て／残る問題 |
|---|---|---|
| 1 | 実写の引きが同じ道路わきの低い位置（K・S）ばかり。画の種類は「寄り（N）」と「引き（K・S）」の2つしかない | 間に N と図解をはさむ。根本は撮り足し（標尺の目盛りの接写5秒、2か所で読む画）が要る |
| 2 | S は 480p。締めの一番長い画（約6秒）が甘い | 寄らない。大画面での見え方は試写で判断。差し替えるなら K 14–19 秒（立ってのぞく引き） |
| 3 | 「目線が水平な線になる」は、レベルが自動で水平を保つ仕組み（据えて気泡を合わせる）を言っていない | 子ども向けには省く判断。測量士に「言い過ぎ・言わなさ過ぎ」を聞く |
| 4 | B5 の図は情報が多い（地面・水準点・標尺2本・矢印・0・読み2つ・差・文字）。10 秒で追えるか | 1つずつ順に出し、矢印は 1.2 秒で消す。試写で子どもに「どっちが低い？」と聞いて確かめる |
| 5 | 「なぜ大事か」が「地図や道路の図面」で、基準点パートと同じ言い方 | 別の中心の絵「海からはかる」なら「海から何メートル」という身近な数字が使える（下の問1） |
| 6 | 往復観測は声だけで、画がない | 尺の都合。監修で「言わない」となれば N6 を「何度もはかって確かめます」に |
| 7 | 環境音が合成の風（基準点パートの草原用）。現場は車の通る道 | 試写1では仮。車の音を足すかは問4 |
