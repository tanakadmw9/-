## 2026-10-27 独立レビュー（B1.2）への対応

| 指摘 | 対応 |
|---|---|
| S06 の使い回しが目立つ（重要） | **一部対応**。2回目は1.1倍で右へ寄せた別の構図にし、上に点・地図・道路の線を描く。冒頭と同じ道に意味を重ねる再登場として残す（S10 を7秒止めるより良いと判断）。試写で気になれば再検討 |
| 「つないで確かめる」が画で伝わらない（重要） | 対応。S10 の点の輪を 37.3秒から灯し、1.6秒かけてつないで閉じる（以前は閉じた直後に切っていた）。S06 の点を結ぶ線を「つないで」の発話（42.1秒）に合わせて出す |
| 帯の文字の問い→すぐ「いいえ」で子どもに分からない（重要） | 対応。N7 を 38.9秒に遅らせ、文字を約2秒読ませてから答える。声の問いに戻すと最後の一音に収まらないため文字のまま |
| 等高線が人を横切り、空中の直線に見える（重要） | 対応。等高線は右奥の斜面（人にかからない所）に、斜面に沿った曲線で描く。点を結ぶ線も人にかからない3点だけに |
| 金属標がコインやボタンに見える・色の決まりに反する（重要） | 対応。金属標は白（＝もうわかっている点）の平らな円板に変え、琥珀は「探して」で広がる輪（2回）だけに。S06 の琥珀の点（新しい点）が白い金属標に変わる＝「新しい点が基準点になる」。靴は全体が見える高さに上げた。寄りを 8%→10% に |
| 「基準点」ラベルが人の脚に重なる（重要） | 対応。TS の脚元の輪の右の草地に移し、引き出し線でつなぐ |
| 分割画面のパネルが小さい（重要） | 対応。パネルを 856→952px にし、図を1.1倍。ラベルは 44px 以上 |
| パネル上端に切れた丸（軽微） | 対応。SVG の位置の上書き（GSAP の y）で「？」と札が隅へずれていた不具合を直した |
| 小見出し・クレジットが小さい、指差しの「？」が小さい（軽微） | 対応。小見出し 38px、クレジット 36px、「？」を約1.5倍・点線を太く |
| 金属標→エンドカードの間の黒（軽微） | 対応。タイトルが黒の上にすぐ出るようにした |
| 社名入りヘルメット、S01 の点は既知点か、放射法の絵（要監修） | 依頼者・技術監修に確認する事項として提出時に伝える |
| 「角度」と言わず「向き」 | 意図どおり（research §2 の家族向けの言い換え）。試写で通じるか確かめる |
