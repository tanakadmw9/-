## 0. この角度で考えたこと

家族がいちばん見たいのは、家族が働く姿。水準測量の素材を見直すと、この仕事は**ひとりではできない**のがはっきりわかる：

- K の 24 秒間、遠くの標尺手は**一度も動かない**。のぞく人が読み終わるまで、ものさしをまっすぐ持ってじっと待っている。
- のぞく人は、遠くの仲間のものさしを、**真横にしか向かない望遠鏡**で読む。読んだ数字は、その場で**黄色い手帳**に手で書く。
- S 168〜172 では、標尺手がものさしを持って機械の横を通り、**前へ**歩いていく。

つまり、このパートの「しくみ」と「意味」は、**人の動きそのものの中にある**。図解は、その人の動きを「見えるようにする」ためだけに使う。

**このパートが背負う範囲**（1本目の決まりに従う）：「水準測量は、測量部門の中で**高さ**をはかる作業。その高さが、道の図面のもとになる」まで。会社全体の意味（まちづくり、毎日の暮らし）は背負わない。

**素材の扱いで先に決めること**（両案に共通）
- 画面に入る**案内標識・店の看板・横断幕・車のナンバー・ヘルメットの名札**は、切り出しで外すか小さくぼかす。K は窓 `470,100,1450,816`（1.32倍）を「引き」の基本にすると、標識・看板・横断幕が外れる（ナンバーだけぼかす）。K の寄りは窓 `470,150,1200,675` か `820,100,1200,675`（1.6倍）。S は上端の標識を外すため y≥75（1か所目）／y≥15（2か所目）。N はヘルメットの名札と機械のメーカー名を小さくぼかす。
- 機械は光学の自動レベル。**光も電子音も出さない**ので、レベルの上に「ピッ」などの電子音を置かない（前のパートの TS との混同を防ぐ。foundation §2.4）。シリーズ共通の「ピッ」は章扉とエンドカード（紙の上）だけ。
- 照準（十字＋円）は人のいる実写に出さない。このパートの形の合図は「**真横の点線**」にする。

## 案A「ふたりの一本線」

### A-1. 名前と一文
**ふたりの一本線**：のぞく人と、遠くでものさしを持つ人。ふたりのあいだに通る「真横の一本の線」で高さをはかり、その高さを道の工事の場所まで運んでいく作業。

### A-2. 持ち帰る言葉3つ／締めの一文
1. 「**ふたりで、高さをはかる**」
2. 「**真横にのぞいて、ものさしを読む**」
3. 「**高さを、道の工事の場所まで運ぶ**」

締め：「**のぞく人と、持つ人。ふたりで、高さを運ぶ。それが、水準測量です。**」（画面の文字は「ふたりで、高さを運ぶ」）

### A-3. 中心の絵と「なるほど」
- **家で子どもが再現できる絵**：ひとりが机の高さに目を合わせて真横を見る。もうひとりが少し離れて、ものさしを立てて持つ。「目の線が、ものさしのどこに当たるか」を読む。床が低い所にものさしを持っていくと、数字が大きくなる。
- 言葉：「真横の線」「ものさしを前へ運ぶ」
- **見る前**：「高さって、上からはかるの？　機械をのぞいて何を見てるの？」「遠くで立っている人は何をしているの？」
- **見た後**：「遠くの人のものさしに、真横の線を当てて読んでいたんだ。**数字が大きいほど、そこの地面は低い**。だから、ものさしを前へ運んで読み比べれば、地面の高さの差がわかる」
- 第二の小さな「なるほど」：「この機械は**真横しか見られない**」（上にも下にも向かない望遠鏡。それが高さをはかる道具になる理由）

### A-6. シリーズの中の位置
- 1本目は「**点**」（位置の目印をつくる。照準が一点に合う。光ではかる）。2本目は「**線**」（二人のあいだの真横の線で高さをはかる。目で読む）。**点 → 線**、**位置 → 高さ**、**光 → 目**、**機械とプリズム → 人と人**。続けて見ると、対になっているのがわかる。
- 1本目の締め「ほかの測量が使う “はじまりの点”」に対して、2本目は「高さを運ぶ」。どちらも「ほかの仕事が使うもとをつくる」役で、言葉はかぶらない。
- 章扉は共通（標尺のアイコンが灯る）。エンドカードは「照準がアイコンに戻る」の代わりに「二人と線がアイコンに戻る」（形は共通、中身はこのパートのもの）。

### A-7. 実写と図の割合、角度の工夫
- 実写 約36秒（51%）、図 約29秒（章扉・看板の動き・高さの差・リレー・道の線・エンドカード）、黒 0.5秒。図の連続は最長 B7後半〜B8前半の約10.1秒。
- 角度：K の引き（10秒、ゆっくり寄る）→ 図 → N の寄り（顔）→ 図 → S の近い標尺 → 図 → K の寄り（書く手）→ S の早回し → S の載せる手 → S の整準の手 → 図 → N の寄り → S の引き。**同じ素材・同じ大きさが2回続く所はない**。
- N の視線は K・S と逆（左→右）。N の前は必ず図（向きのない目盛りの寄り、道の線）にして、逆向きの切り返しを作らない。
- 480p の S は、動いている所（標尺手が抜ける、早回し、載せる手）と最後の引きだけに使い、甘さが目立つ静かな長回しにはしない。

### A-8. この案の弱点（本気で）
1. **標尺手の顔がどこにも映らない**。「人が主役」と言いながら、二人目は最後まで遠くの小さな姿。家族の一方は「うちの人が見えなかった」と感じる（撮り足しでしか直らない）。
2. **しくみの半分は撮れていない**。後ろの目印で読む場面は図だけ。素材に映る標尺は1本で、本当に「後ろ→前」の順に動いたのかも未確認【要確認】。
3. **核の「なるほど」（数字が大きいほど低い）は、前の案（v5）の核と同じ物理**。見せ方（クイズではなく、仲間がものさしを運ぶ）は違うが、依頼者が「また同じ」と感じる恐れがある。
4. 「高さを、道の工事の場所まで運ぶ」は、仮の高さの目印（仮BM）を置く作業の言い換え。**この現場がその作業だったかはわからない**。縦断測量や別の作業なら、B7・B8 の言葉を替える。
5. **輪郭のなぞり**は、雑に作ると安っぽい「切り絵」に見え、「AIっぽい」と言われる危険がある。単純な外形で、線の太さと描く速さを厳密にそろえる必要がある（スクリプトで再現できる形にすること：輪郭を SVG のパスとして部品に持つ）。
6. 「ふたりで」と言い切るが、実際の班は記帳・交通誘導を入れて3人以上のことも多い【要監修】。
7. K が冒頭10秒を占め、ほとんど動かない。最初の拍で子どもが離れる心配がある（ゆっくりの寄りとラベルで支えるが、強くはない）。
8. 1本目の「何度もはかって確かめる」に当たる**往復の確かめ**を入れていない（シリーズで同じ拍をくり返さないため）。測量士には物足りないかもしれない。

## 案B「手で書いた数字が、道になる」

### B-1. 名前と一文
**手で書いた数字が、道になる**：ものさしを読み、黄色い手帳に手で書いた一つ一つの数字が、並べると地面の形になり、新しい道の図面のもとになる作業。

### B-2. 持ち帰る言葉3つ／締めの一文
1. 「**機械で、ものさしの数字を読む**」
2. 「**読んだ数字を、手で書く**」
3. 「**数字をつなぐと、地面の形になる**」（それが道の図面のもと）

締め：「**ていねいに書いた数字が、道の形になる。それが、水準測量です。**」【要監修】（画面の文字は「ていねいに書いた数字が、道の形になる」。言い過ぎなら「道の図面のもとになる」に替える）

### B-3. 中心の絵と「なるほど」
- **家で子どもが再現できる絵**：紙の上のほうに、まっすぐな横線を1本引く。そこから、手帳の数字の長さだけ、下へ棒をたらす（大きい数字は長く）。棒の先を線でつなぐと、**地面の形**が出てくる。
- 言葉：「黄色い手帳の数字」「横線から、たらす」
- **見る前**：「機械をのぞいて、手帳に何を書いてるの？　数字なんて書いて何になるの？」
- **見た後**：「数字は、**機械の真横の線から地面までの長さ**だったんだ。だから大きい数字ほど地面が低くて、並べてつなぐと地面の形がそのまま出てくる。それで、新しい道の坂を決めるんだ」
- 専門の裏づけ：これは道路の**縦断測量**（道の中心に沿って、決まった間隔で地面の高さをはかり、縦断図をつくる）の考え方そのもの。1回据えた機械から、何本もの点のものさしを読む（中間の点を読む）ので、「一本の横線から何本もたらす」絵は単純化ではなく、ほぼそのまま【要監修】。横線の高さは、先に高さがわかっている目印で確かめておく（最初の1本は紺の目印の上に立てる）。

### B-8. この案の弱点（本気で）
1. **81秒に対して、使える画の種類が少ない**（実質 K・N・S の3つ）。B7・B9 で「のぞく・書く」をくり返すので、ゆるんで見える恐れがある。短くするなら B9（4小節）を落として28小節＝70.8秒（曲は1〜16＋25〜36）にできる。
2. **野帳は K では小さい**（手元が約110×50画素）。「手帳の中へ入る」は、写真の寄りではなく図の紙に置き換える作り物の寄り。数字も作り物なので、「イメージ」と明示しないと実際のデータに見える。
3. 「縦断測量（一本の線から何本も読む）」の絵が、**この現場の作業と合っているか未確認**。仮BM の設置や別の作業だったら、B6 の「横に並ぶ点＝道に沿った地面」の言い方を変える【要監修】。
4. 「新しい道の高さと坂を決める」のは設計の仕事。**測量部門のパートが設計の役まで背負っている**ように見える（「図面のもと」と言って踏みとどまっているが、締めの「道の形になる」は言い過ぎの恐れ）。
5. 核の絵（上に横線、下へ長さ）は、前の案 v5 の「見えない水の面と深さ」と**同じ骨組み**。水のたとえとクイズは使わないが、依頼者には近く見えるかもしれない。
6. 1本目の「点つなぎ」（点から線が描かれる）と**見た目が似る**。続けて上映すると「また線が描かれる図」に見える。線の色・描く向き・出どころ（点ではなく、手帳の数字）で違いを出す必要がある。
7. 手と顔に寄るので、**標尺手はさらに小さい存在**になる（遠くの姿と歩く後ろ姿だけ）。
8. 図の数字（1m20〜1m70）は、隣どうしの差が実際の道より大きい。縦断図はもともと**縦を横の10倍ほどに伸ばして描く**ので嘘ではないが、測量士には説明が要る【要監修】。

## 4. 専門の目で押さえたこと（両案の事実の土台）

- レベルは**望遠鏡が水平にしか回らない**（上下に向かない）。この素材の機械は自動レベル：丸い気泡で大まかに水平にすると、中の振り子のしかけが視線を自動で水平に保つ（foundation §2.2 の7）。光は出さず、人が目で目盛りを読んで野帳に書く。
- 読み＝**視線（真横の線）から、標尺を立てた地面までの長さ**。だから読みが大きいほど地面は低い（高さの差＝後ろの読み−前の読み）（§2.2 の4）。
- 道路の仕事（路線測量）では、近くの水準点から**仮の高さの目印（仮BM）**を路線沿いに設ける（3級水準測量など）。そこから、道の中心に沿って決まった間隔（例：20m）の点の高さをはかる**縦断測量**、道を横切る断面をはかる**横断測量**へ進む。発注の内訳でも、仮BM設置・縦断・横断が別の項目になっている [R1][R2]。
- 縦断測量では、1回据えた機械から何本もの中間の点を読む（器械高から読みを引いて地面の高さを出す）。縦断図は縦を横より大きく伸ばして描くのがふつう【要監修：倍率】。
- 道路は雨水を端へ流すため横にもわずかに傾けてある（車道は 1.5〜2% が標準、1mで1.5〜2cm）[R3]。今回の両案では声に出さない（v2.3・v5 で水の話をくり返したため。必要なら案B の B8 に一言足せる）。
- 精度・許容差・視準距離の数字は声で言わない（§2.2 の5【要監修】、§2.4）。

## 6. どちらを推すか

**推す：案B「手で書いた数字が、道になる」**

理由
- 判断の優先順位の1番（家族に仕事の中身と意味が伝わるか）で強い。「手帳の数字 → 下へたらす → つなぐと地面の形 → 道の図面のもと」が**一続きの動き**で、しくみ（読み＝線から地面までの長さ）と意味（道の坂の図面）が同じ絵の中で起きる。子どもが紙と鉛筆で再現できる。
- 2番（正確さ）でも強い。一本の横線から何本も読んで地面の形を出すのは、道路の縦断測量のやり方そのもので、単純化のうそが少ない。
- 「人が主役」も守れる：実写が約63%、見せ場の起点が**家族の手（書く手）**。数字の一つ一つが「誰かが目で読み、手で書いたもの」だとわかる。
- 案A は「二人」の物語としては一番強い（遠くの人が同じ大きさになる動きは、人が主役の看板として魅力がある）。ただ、真ん中の「高さを工事の場所まで運ぶ」が抽象的で、なるほども v5 と同じ物理に頼る。**案A の「遠くの人が同じ大きさになる」動きは、案B の B4（9〜10小節）に移植できる**（K の二人を横から見た図に組み替え、そこから B5 の書く手へ）。比べて決めるときの第三の道として示す。
- ただし §5 の1（現場の作業）の答えが「仮BM の設置」なら、案A のほうが事実に合う。監修の答えを先にもらいたい。
