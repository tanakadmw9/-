## 0. 要点（ここだけ読めば足りる）

1. **原稿の骨組みは事実として正しい。** 「目印（基準点）をつくる → 角度と距離をはかる → 既知の点から新しい点の位置が決まる → 何度もはかって確かめる → その点を使って地図や道路の図面をつくる」は、準則の考え方と合っている。大きな誤りはない。
2. **直すと良くなるのは2か所。**
   - N3「その目印を、『基準点』といいます」→ **「位置が正確にわかっている目印を、『基準点』といいます」**。基準点の本質は「しるしがあること」ではなく「その位置（座標と高さ）がわかっていること」。N5a「位置がわかっている点から」への伏線にもなる。
   - N6「何度もはかって、ずれがないかを、しっかり確かめます」→ **「何度もはかり、ほかの目印ともつないで、ずれがないかを確かめます」**。実際の確認は「同じ所を何度もはかる」と「ほかの既知点に結んで食い違いを見る」の2つ。後半を足すと測量士が見ても納得する。
3. **D2 は「放射法」の絵だが、それで良い。** 実際の基準点測量は既知点から出発し、新点をつないで別の既知点に結ぶ「多角方式（トラバース）」が基本。D2 はその1区間だけを見せている、と考えれば正しい。B7・N6 で「つなぐ」を言えば補える。
4. **実写 S04 の三脚の下は木杭。** 永久的な基準点のしるしは金属標・標石が基本で、木杭は仮の点に使うことが多い。D0 を金属標で描くと「映像の杭と違う」と言われうる。D0 は**金属標（丸い金属の板に十字）**で描き、「実写の点は何か」を測量士に確認する（§5 Q2）。
5. **章扉の注意**：準則では「水準測量」は第2編「基準点測量」の中の1章。業務名としては別々に呼ぶのが普通なので並べてよいが、アイコンは部門の実際の業務名に合わせる（§3）。
6. **声で言わないほうがいいこと**：精度の数字（「数ミリ」など）、「GPS」（正しくは GNSS。言うなら「人工衛星」）、全国の点の数（使うなら国土地理院の数字：電子基準点 約1,300点、三角点 約10万9千点）。

### 1.1 言わないほうがいいこと・言うなら正しく

| 表現 | 理由 | 使うなら |
|---|---|---|
| 「GPSではかる」 | GPS はアメリカの衛星だけの名前。測量では日本のみちびき等も含めて GNSS と呼ぶ | 「人工衛星の電波で」。画面の文字なら「GNSS（人工衛星）」 |
| 「ミリ単位で正確」など精度の数字 | 級・方法・条件で変わる。誤差の許容範囲は準則の表で決まっていて、一言で言えない | 数字は言わない。「正確に」で足りる |
| 「日本中に〇万点」 | 数え方（国の点か、自治体の点も含むか）で変わる | 国土地理院の数字：電子基準点 約1,300点（約20km間隔）、三角点 約10万9千点、水準点 約1万6千点、国の基本基準点 計 約13万点 |
| 「基準点は国がつくる」 | 国の点（基本基準点）もあるが、会社が公共測量でつくる点（公共基準点：1〜4級基準点）がこの映像の主役 | 言うなら「国の点をもとに、工事などに必要な点をふやす」 |
| 「一度はかれば決まる」と取れる絵 | 実務は必ず繰り返しと点検がある | N6 の言い換えで対応済み |

| 閉合差 | つないだときのずれ | 歩いて元の場所に戻ったら、ちゃんと元の場所か |

## 3. 測量部門の仕事の一覧（章扉アイコンの案）

建設コンサルタントの測量部門で一般的な業務。準則の編立て（第2編 基準点・水準、第3編 地形・写真、第4編 路線・河川・用地）を土台に、近年の業務を足した。**部門の実際の業務名は依頼者に確認が必要【要確認】**。

### 3.1 推奨の5つ（章扉の並び＝現場の流れの順）

| 順 | 章扉の名前（6字以内） | 中身（家族向け） | アイコンの形（紺の線画） |
|---|---|---|---|
| 1 | **基準点測量** | 位置の目印をつくる | 三脚＋▲（三角点の地図記号に近い形）|
| 2 | **水準測量** | 高さをはかる | 標尺（目盛りの棒）とレベル |
| 3 | **地形測量** | 土地の形をはかって地図にする | 等高線の山＋ドローン |
| 4 | **路線測量** | 道路や水路の線を決める | 曲がる道路の中心線 |
| 5 | **用地測量** | 土地の境目をはかる | 境界杭と区画線 |

### 3.2 部門によって入れ替える候補

| 名前 | 中身 | 向いている部門 |
|---|---|---|
| UAV測量／3次元測量 | ドローンやレーザーで立体の形をはかる | ICT・点群を売りにしている部門。「地形測量」と入れ替え可 |
| 河川測量 | 川の断面や川底をはかる | 河川の仕事が多い部門 |
| 深浅測量 | 海や湖、川の深さをはかる | 港湾・河川 |
| 地籍調査 | 一筆ごとの土地の境界と面積を調べる | 自治体の地籍事業を受ける部門。「用地測量」と近い |
| 変位計測（モニタリング） | 橋や斜面が動いていないかをはかり続ける | 維持管理の仕事がある部門 |
| 写真測量（航空・UAV） | 写真から地図をつくる | 空中写真の部門 |

### 3.3 章扉の設計への示唆

- 並びは「現場で使う順」（目印 → 高さ → 形 → 線 → 境目）にすると、基準点が左端＝最初に来て、「はじまりの点」と形でもそろう。
- 基準点と水準を並べると「位置」と「高さ」のペアになり、子どもにも違いがわかる。
- アイコン名は書く場合でも4〜5字（「基準点」「高さ」「地形」「道路」「境界」の短縮形も可）。読ませないなら出さなくてよい（content.md §5 のとおり）。

### 4.1 これらから取り入れたいこと（演出への提案）

1. **「見たことある」を起こす**：歩道や公園にある金属標は、家族が実際に見かけているもの。D0 を金属標で描き、可能なら近所の標識の写真（shot_log の依頼2）を1枚入れると「身近にある」が伝わる。締めのあとに小さく「街の中で探してみてね」を入れる案も（会場の雰囲気次第）。
2. **人の表情で終える**：業界の紹介動画はどれも、最後は人の顔か背中。構成Aの B8（S02→S10）はこれと合っている。
3. **会社全体の言葉とぶつからないこと**：「まちづくりのはじめの一歩」は業界でよく使う言い回しで、会社紹介側が使う可能性が高い。このパートの「はじまりの点」は「測量の中の」役割に絞っているので重ならないが、上映全体の台本を見られれば確認したい。

## 5. 技術監修（社内の測量士）に聞くこと

選択式で、試写2の前に回答をもらう想定。

1. **N3 の言い換え**：「位置が正確にわかっている目印を、『基準点』といいます」でよいか／元のままでよいか
2. **実写の点**：S04 の三脚の下の木杭は何の点か（1〜4級基準点／仮設点／TS点）。D0 を金属標で描いてよいか
3. **D2 の描き方**：既知点A・方向の目印B・新点P の1区間（放射の形）で、基準点測量の説明として許容できるか／多角（つないで別の既知点へ結ぶ）の形にすべきか
4. **N6 の言い換え**：「何度もはかり、ほかの目印ともつないで、ずれがないかを確かめます」でよいか
5. **この現場で使った方法**：TS だけか、GNSS も使ったか（使ったなら、声で言わなくても画面の文字で一度触れるか）。何級の基準点か
6. **章扉の業務名**：部門で実際に呼んでいる業務名と並び順（§3）
