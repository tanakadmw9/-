# チームB コンセプト指示（監督より） 2026-10-27

A案（構成A「はじまりの点」：章扉のアイコン列→タイトル→紙の図解 D0/D1/D2→点つなぎ→締め、New Departure、24小節、ナレ約7割）とは**意図して違うもの**を作る。品質の基準（docs/01・04・05・07、research/kijunten.md の事実確認）は同じ。

## 1. 一言のコンセプト
**「地面に“住所”をつける」**——問いかけで始まり、観客が自分で答えに気づくドキュメンタリー。
- 基準点＝「位置（住所）が正確にわかっている点」。基準点測量＝「わかっている点から、新しい点の住所を決める仕事」（research §2 の「既知点＝もう住所が決まっている点」）。
- 部門の中の位置づけは、ナレで一覧を言わず、「ほかの測量の出発点になる」で1回だけ言う（会社全体の意味は背負わない＝A案と同じ制約）。

## 2. A案との違い（この5つは守る）
1. **入り方**：章扉ではなく、実写の**コールドオープン**（S06 農道を歩いてくる一行、環境音だけ）と、観客への**問い**「この人たちは、何をしに来たのでしょう」。タイトルは問いの答えとして10〜15秒あたりで出す。
2. **画づくり**：**シネマスコープ（2.39:1）の上下黒帯**。焼き込みテロップを帯で隠せるので、拡大は S01/S02 で約1.06倍、S03以降は等倍（A案は1.2〜1.41倍）＝画質で勝つ。文字は原則**帯の中**に置き、人の顔と画にかぶせない。
3. **図解のしかた**：紙の別画面に切り替えない。**実写の上に直接描く（AR風の注記）**。しくみの説明は1回だけ、**分割画面**（左：実写の人、右：紺の「観測パネル」で真上から見た図）にして、説明中も人が画面から消えない。実写の割合は8割以上を目標。
4. **語り**：ナレは少なく（尺の5割前後、約150〜180字）、**問いかけ→答え**の形。間と環境音を生かす。声は冥鳴ひまり（承認済み）だが、A案より低め・ゆっくりのドキュメンタリー調。
5. **締め**：家族が**帰り道にできること**で終える：「道ばたの丸い金属のしるし」（金属標）を線画で見せ、「探してみてください」。【要監修：見かける金属標がすべて基準点ではない→言い方を工夫】。A案の章扉に戻る円環構造は使わない。

## 3. 音楽
- 第一候補：**緑色の木漏れ日（ioni）**——アコースティック、穏やか、約86BPM、編集自由。A案のピアノ曲 New Departure は使わない。96kbps の低音質が欠点なので、帯域と会場での聞こえ方を確認すること。
- 次点：新緑芽吹く頃（テンポが揺れる・大幅改変禁止）。曲の終わりは曲本来の終止を使い、フェードアウトで逃げない。
- 曲は冒頭から鳴らさない（コールドオープンは環境音と足音だけ→問いのあとに曲が入る）。

## 4. 尺と素材
- 目標 60〜66秒。実写約40秒のうち使えるのは約33〜36秒。スロー・水増しはしない。
- 効果音は少なく、**現場の音（足音・草・鉛筆で記録する音）を厚く**（assets/se/foley、ambience）。電子音は「はかる」「住所が決まる」の2つまで。
- 素材は /mnt/project-files/assets/ と /mnt/project-files/dova/ のもの。新しい素材は台帳に記録。
