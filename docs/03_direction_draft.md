# 03 演出設計の叩き台（構成・ナレーション・図解）

> **これは正解ではなく叩き台。** Claude Code は Phase 2 で、まずこの案の弱点を5つ以上挙げ、別案を少なくとも1つ検討したうえで、自分の推奨案を理由つきで出すこと。数字や断定には【要監修】を付けてある。

## 1. 演出コンセプト：「最初の一点」

- 物語の芯：**まだ何もない場所に最初の一点を打つ人たち**。その一点が、道路や橋、毎日の暮らしにつながっていく。
- 視覚モチーフ：**照準（TSの望遠鏡の十字線）と「点」**。タイトルで照準が一点に合い、図解で点が増えて網になり、最後にまた一点に戻る（はじめと終わりを同じモチーフで閉じる）。
- 観客の体験の流れ：**現場に連れていかれる → しくみが「わかる」 → 生活とのつながりに自分で気づく → 家族の仕事への誇り**。
- 「発見」の仕掛け：答えを先に言わず、「両岸からつくる橋が真ん中でぴったりつながるのは――」で一瞬止め、観客が考えたところで答えを出す。

## 3. 構成B（比較用）：問いから入る

- 0:00〜：図解D4の「両岸から橋がのびて、真ん中で出会う」アニメと問い「なぜ、ぴったりつながるの？」
- → 実写で現場へ「その答えは、ここにあります」→ しくみ → 答え合わせ → 日常。
- 長所：子どもの好奇心をすぐつかむ。短所：人ではなくアニメから始まる。答えが中盤で出るので終盤の山が弱くなりやすい。
- Phase 2 でA・Bを比較し、推奨と理由を書くこと（両方の簡易アニマティックを作って見比べてもよい）。

- 読む速さは子どもを考えて**1分あたり250〜280字**程度。文と文の間は0.4〜0.8秒。

- 最終的には社員の肉声で録り直す前提（docs/05）。

## 5. 図解の設計（D1〜D5）

共通：紙のような明るい背景に、うすい方眼（地形図を思わせる）。**既知・基準＝紺**、**はかる・新しい＝オレンジ**の2色だけで意味を色分けする。一度に動くのは1か所。言葉とその言葉の絵は**±0.3秒以内**で同時に出す。

### D1 実写から図解へ（S09を使う）
1. S09を流し、TSとプリズムがはっきり見える瞬間で**静止**（フレームはPhase 1で選ぶ）。
2. 実写の彩度と明るさを0.6秒かけて落とす。
3. TSのレンズからプリズムへオレンジの線がのび、光の粒が行って戻る（「角度」「距離」の言葉に合わせる）。
4. 対象物のすぐ横に引き出し線つきラベル：「トータルステーション（角度と距離をはかる機械）」「プリズム（光をはね返す鏡）」。
- 注意：ラベルの位置は静止画上で座標を測って置く。カメラが動く区間に追従させない。

### D2 真上から見る（しくみの核心）
1. D1の線画だけを残して実写を消し、視点を真上へ（3D回転でうまくいかなければ、ディゾルブでよい）。
2. 既知点A（紺の△、「位置がわかっている点」）と、遠くの既知点B（「方向の目印」）。AからBへ点線。
3. AのTSがBの方向からPの方向へ回り、**角度の弧**がのびる →「角度」。
4. AからPへ**距離の線**がのびる →「距離」。
5. Pにオレンジの点が打たれ「新しい基準点」。座標の数字が回って止まる（数値は例示と分かる表示にする）。小さなクリック音。

### D3 はかりつなぐ・確かめる
1. 視点を引き、P→Q→Rとリズムよく点がつながる（BGMの拍に合わせると気持ちよい）。
2. 最後に別の既知点C（紺の△）にたどり着き、計算の点とCの位置を拡大して比べる →「ずれを確認」✓。
- 「ずれを無理に合わせる」ように見えない表現にする【要監修】。

### D4 基準点から、道路と橋へ
1. さらに引くと、点の網が地図全体に広がり、川が現れる。
2. 網の上に道路の設計線（紺の点線）が引かれる。
3. 川の両岸から橋がのびていき、N7aの「――」で一瞬止まる（BGMも抜く）。
4. N7bで、両側の橋が**同じ基準点**と線でつながって光り、真ん中でぴったり合う。

### D5 図から日常へ
- 線画の道路・橋が、完成した実物の写真（自社実績・掲載許可済み）へクロスディゾルブ。写真が無ければ、車や歩く家族を加えた線画で完結させる。
- 標識写真（9b）がある場合：写真の上に照準が合い「みなさんの近くにも」。

## 6. リズムとつなぎ

- 平均カット長は3〜4秒。情報を読むカットは長め、気持ちのカットは短め。
- ナレーションはカット頭から0.3〜0.5秒後に入る。カットの切れ目と文の切れ目を合わせる。
- 場面転換では環境音を映像より0.3〜1秒先に入れる／残す（J/Lカット）。
- 大事な一言の前に「間」を置く（音楽を0.5〜1秒抜く）。
- カット点・図解の動きは音楽の拍や小節頭に寄せる。ただし**言葉が最優先**。
- トランジションは基本カット。特別なつなぎは「照準」と「静止→図解」の2種類だけに絞り、乱用しない。

## 7. 理解を助ける原則（学習研究の知見をこの作品に当てはめたもの）

マルチメディア学習の研究（Richard E. Mayer『Multimedia Learning』ほか）の原則を、この作品の設計にこう使う。

| 原則 | この作品での実装 |
|---|---|
| 一貫性：関係ない装飾・音を足さない | 光沢・グラデ・意味のない効果音は入れない |
| 信号化：見るべき所を示す | 照準・ハイライトで注目先を1か所ずつ示す |
| 冗長性：ナレーションの全文字幕は理解を下げることがある | 字幕は全文ではなく**キーワード**だけ |
| 空間的近接：説明は対象のそばに | ラベルは物の横に引き出し線で置く |
| 時間的近接：言葉と絵は同時に | ±0.3秒以内で同期 |
| 分割：一度に詰め込まない | 「角度 → 距離 → 位置が決まる」を3拍に分ける |
| 事前学習：用語を先に | 用語3つは仕組みの説明の前に1回ずつ紹介する |
| 音声：機械の声より人の声 | 本番は社員の肉声 |
| 個人化：会話調 | 「みなさん」「私たち」で語りかける |

## 8. 他パートとの関係

- このパートの型（章タイトル・テロップ・図解・音の設計）を、測量の他作業や設計・調査・営業パートで**使い回せるテンプレート**として残す。
- 本番の並び順が「測量 → 設計」なら、最後に「この位置をもとに、次は設計が、まちのかたちを描きます」などの橋渡しの一文を追加できる（要相談）。
- 「両岸からの橋」の例が他パートと重ならないか、全体構成の担当と確認する。
