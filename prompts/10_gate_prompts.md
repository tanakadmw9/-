# ゲートごとに渡すプロンプト

## ゲート1 のあと（絵コンテを承認したとき）

```
絵コンテと原稿を確認しました。
- 採用する構成：【A ／ B ／ 修正版】
- 直してほしい点：
  - 【タイムコードや拍の番号＋感じたこと】
- 技術監修の確認結果：【まだ ／ 済み：指摘内容】
決定事項を docs/decisions.md に記録してから、フェーズ3（デザイン）に進んでください。
スタイルフレーム、色補正の比較（2〜3案）、焼き込みテロップの処理の比較（カットごと）を作り、ゲート2で止まってください。
```

## ゲート2 のあと（見た目を決めたとき）

```
デザインを確認しました。
- スタイル：【案○で。直す点：】
- 色補正：【案○】
- 焼き込みテロップの処理：【カットごとの指定、または「あなたの推奨どおり」】
- BGM：【audio/bgm/ に置いた ○○.mp3 を使う ／ 候補の条件と探し方を出して】
決定事項を記録してから、フェーズ4（アニマティック）に進んでください。仮ナレは VOICEVOX で作り、使ったキャラクターと規約を台帳に記録してください。
書き出し後は自動チェックとレビュー用サブエージェントの審査を済ませてから、ゲート3で止まってください。
```

## ゲート3 のあと（試写1の感想を渡すとき）

```
アニマティックを試写しました。止めずに1回、止めながら1回見た感想です。
- 【0:12 ここで何の話か分からなくなった】
- 【0:35 角度と距離の図解が速い】
- 【0:50 「間」がもう少し長い方がいい】
- 全体の印象：【】
直し方は任せます。指摘ごとに原因と直し方を短く示してから直してください。
そのあとフェーズ5（本制作）に進み、ゲート4で止まってください。
```

## ゲート4 のあと（技術監修と対象者テストの結果を渡すとき）

```
試写2（技術監修）と試写3（対象者テスト）の結果です。
- 技術監修の指摘：【】
- アンケート結果：【問1〜3の回答の要約、問4で挙がった場所】
合格の目安（docs/07 §4）に届いていない点を特定し、直す計画を示してから直してください。
本ナレーションを audio/vo_final/ に置きました【置いた ／ まだ】。置いた場合はフェーズ6に進んでください。
```

## ゲート5 のあと（最終）

```
マスターを会場（または同等の環境）で確認しました。
- 【問題なし ／ 直す点：】
問題がなければ、docs/07 §5 の検収基準を一つずつ確認した結果と、納品物一式（deliver/）の一覧を出してください。
最後に、このパートで作った型（部品・規定・手順）を他のパートで使い回すための「次のパートの作り方」メモを docs/next_segment_guide.md にまとめてください。
```

## 困ったときに使う言い方

- 「もっとプロっぽく」より：
  `この場面の目的を一文で言い、それが今の画と音で達成できていない理由を3つ挙げ、直し方を2案出して。`
- 何かが雑に見えるとき：
  `docs/04 §8 の禁止事項と検収基準に照らして、今の版を自己点検して。当てはまる箇所をタイムコードつきで。`
- 進め方が速すぎる・勝手に決めているとき：
  `好みが分かれる判断は比較できる形にして、ゲートで聞いて。`
- 会話が長くなって前の話を忘れていそうなとき：
  新しいセッションを開いて `CLAUDE.md と docs/decisions.md を読んで、今どのフェーズかと次にやることを教えて。`
