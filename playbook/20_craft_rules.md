# 20 作り方の決まり（数値つき）

規定の全文は docs/04（見た目と動き）、docs/05（音）、docs/07（検査と検収）。この章は、v4.1〜v4.10 で**実際に効いた・直した**決まりを、理由つきで1か所にまとめたもの。数値は v4.10 の値。

## 1. 構成と時間

| 決まり | 値 | 理由・出どころ |
|---|---|---|
| 尺の物差し | 曲の小節。New Departure 94.9BPM、拍 0.63199秒、1小節 2.528秒、最初の拍 1.9567秒（曲の中） | ナレの長さから尺を決めるとリズムがなくなり、直すたびに全体がずれた（v4.1〜v4.4） |
| 尺 | 24小節＝60.66秒（拍の表 B1〜B8） | 1作業のパートとして長すぎない。シリーズで同じ骨組みを使える |
| 場面の変わり目 | 小節の頭 | 曲の山と画の山を合わせる |
| 場面の中のカット | 拍の頭。**1コマ前**に置く（`cut(bar, beat)`） | 目は耳より先に変化を感じる。ぴったりだと遅れて見える |
| 曲の山との対応 | 8小節（息つぎ）＝「基準点」の定義、9小節（全楽器が入る一番強い頭）＝「はかる」実写、21小節（最後の一打）＝締めの実写 | 曲の構成を地図にしてから画を置く（reference/plans/editing.md §2） |
| ナレの量 | 尺の約7割（v4.10 は 71%）。約230字 | 「間」を音楽に渡す。8割を超えると息苦しい |
| ナレの入り | 場面の変わり目の0.3〜0.5秒後。小節の頭の強い音にぶつけない | 画を見てから聞く順にする |
| 意味の山 | 拍に置く：「ひとつ、」＝アイコンが灯る拍、「基準点測量」＝照準が合う拍、「決まります」＝点が打たれる拍、「はじまりの点」＝締めの文字が出る拍 | 一つの意味は一つの瞬間に |
| 最後の言葉から終わりまで | 1.5秒以上（`20_plan_timeline.py` の assert） | 言い切った後の余韻 |
| 本ナレに替えたとき | 格子（小節）は動かさない。ナレの置き場所を拍単位で直し、収まらない文は原稿を直す | 尺とリズムを守る |

拍の表（v4.10）：B1 章扉→タイトル（0.0–7.6）／B2 人と現場、目印が要る理由（–15.2）／B3 基準点とは（–20.2）／B4 はかる（–27.8）／B5 しくみ（–35.4）／B6 確かめる人（–43.0）／B7 ほかの測量へ（–50.6）／B8 締め（–60.7）。

## 2. 画（実写）

- **焼き込みテロップは切り出しで外す**：S01・S02 は y<765 を使う 1.41倍、S03 以降は y≥180 を使う 1.2倍。カットごとの窓は scripts/02_intermediates.py の CROPS。覆う案は S01 で画面下3割を隠すことになり不自然だった（analysis/compare_burnin.jpg）。
- 自動QC で青い光沢カプセル（焼き込みテロップ）の漏れを毎回検査（HSV の条件は 40_qc.py の冒頭に、元素材で調整した値）。
- 色：全カットをそろえてから全体の調子（緑を下げ、わずかに暖色、ハイライトを抑える＝案B）。カットごとの補正は SHOT_ADJ。圧縮素材なので強い補正はしない。デバンド＋ごく薄いグレイン。
- **動きは理由のある3か所だけ**：タイトルの静止画への寄り（毎秒2%以下）、最後の S10 への寄り（毎秒1.5%）、D1→D2 の「実写が倒れて真上の図になる」動き（約1秒、power2.inOut）。ほかの実写は素のまま。手ぶれ補正はしない。
- **ディゾルブは1か所だけ**（S08 の草原→点つなぎの地図の紙、約1.3秒）。「この土地が地図になる」という意味があるときだけ溶かす。汎用のワイプ・スライド・光漏れは使わない。
- 静止は意図したものだけ（timeline の intended_freezes に理由つきで書く。QC の freezedetect と突き合わせる）。
- 形でつなぐ：章扉のアイコン→S04 の照準、S03 の三脚→D0 の三脚、D1 の静止画→D2、D2 の点P→点つなぎの1点、S10→エンドカードの照準→章扉のアイコン。

## 3. 照準（レティクル）

- 照準（十字＋円）は**物か地面の点にだけ**合わせる。**人の体の上に止めない・通さない**（銃の照準に見える。独立レビュー v4.7 で重要）。
- カットや紙への溶けをまたいで動かすときは、人のいない所（空・草地）でまたぐか、紙がほぼ覆ってから動かす。
- 書き出しのたびに、照準が見える区間を0.07〜1秒ごとのコマで通して確認する（contact シートだけでは間が抜ける）。

## 4. 文字

| 決まり | 値 |
|---|---|
| 書体 | BIZ UDPゴシック（数字は BIZ UDゴシック）。プロジェクト内のファイルから読む |
| 大きさ | 章タイトル 104〜120px、キーワード 64〜72px、ラベル 44〜52px、補足 34〜38px。**34px 未満は使わない** |
| 1行 | 最大16字、最大2行。文節で改行 |
| **表示時間** | **文字数÷4＋1.0秒、かつ1.5秒以上**。画面で「読める濃さ（不透明度×覆われていない割合 ≥0.6）」の区間を実測する（scripts/44_text_timing.mjs） |
| 位置 | タイトルセーフ（左右96px・上下54px）の内側。キーワードは左下、下端から90px以上。顔・機械・プリズムに重ねない |
| ラベル | 対象物のすぐ横に引き出し線。写真を動かす・倒すときはラベルも写真に貼りつける（点が対象から離れない） |
| 例外 | 読ませない文字（章扉の作業名の並び、仮ナレのクレジット）は timeline の text_exceptions に理由を書く。黙って外さない |
| 出し方 | 文字は言葉の**前**に出す（読んでから聞く）。ナレの全文を字幕にしない |

「トータルステーション」は、ナレでは「この機械」と言い、名前は画面のラベルだけにまかせた。ただし家族が家で聞く言葉なので消さず、3.65秒出すために D1 を1拍のばした（v4.9）。

## 5. 図解

- 色は意味で使う：紺＝わかっている・基準、オレンジ＝はかる・新しい（図形だけ。小さな文字に使わない）、紙 #F4F1EA、方眼 #D9D3C4。
- 記号：わかっている点＝紺の△（中心に点）、新しい点＝オレンジの◎、**新しくできた基準点＝オレンジの△**、光の線＝オレンジ5px、観測でつなぐ線＝オレンジの点線4px、設計線＝紺の点線。
- **見せ順で理解をつくる**：D2 は「わかっている点のまとまり → もう一つの点と向きのまとまり → その向きから角度の線が回る → 距離 → 新しい点」。同時に動くのは1か所、次は0.1〜0.2秒ずらす。
- **名前は事実の順に**：D2 では「新しい点」のまま終わる。「新しい基準点」と呼ぶのは、点つなぎで確かめ終わってほかの点とつながり、◎が△に変わる所だけ（v4.8 で順序の逆を直した）。
- 用語は1回だけ、実物の形と一緒に覚えさせる（D0：地面のしるし→三脚が真上に立つ→言葉「基準点」でしるしが灯る）。
- 図解の連続は最長でも約11秒。間に「人」（実写）を挟む（子どもが離れる）。

## 6. ナレーション

### 原稿
- 1文に新しい言葉は1つ。「目印」を先に言ってから「基準点」と名づける。専門用語はナレで言わず、画面のラベルにまかせる（トータルステーション）。
- 「はかる」はひらがな。比喩は誤りにならないものだけ（「住所」「ものさし」は監修で注意が要る。research/kijunten.md）。
- 推定秒＝記号を除いた字数÷5.5。実測はその1.1〜1.4倍（読点の間の分）。
- 長い文は2つに分けて、画の合図に合わせて置く（N1 を N1a「測量部門の仕事のひとつ、」／N1b「基準点測量です。」に分けた：依頼者が選択）。

### 仮ナレ（VOICEVOX：冥鳴ひまり、style 14）
- 全体（F版）：速さ倍率 1.0、抑揚 1.1（上限1.4）、読点の間 1.4倍、高さ +0.04、約330字/分。
  `python3 scripts/11_tts_voicevox.py 14 audio/vo_temp 1.0 1.1 1.4 0.04`
- **文ごとの演出**（comp/narration.json の `vv_dir`）：intent（ねらいを言葉で）、speed、pitch、inton、emph（立てる語）、pause_before、end（soft／firm／cont／soft_long）。全文を同じ調子で読ませると「AIっぽい」。
- **読みとアクセントは手で直す**（`vv_kana`、AquesTalk 風記法）：例「ソクリョオブ'モンノ/シゴトノ'/ヒト'ツ」。両岸＝リョウガン、「つくるのが」の切れ目など。
- 依頼者の反応の順：未調整＝「AIっぽすぎる」→ 文ごとの演出（C）→「落ち着きすぎて内向的」→ 明るく速い（D・E）→「速さを戻して、機械感とイントネーションを直して」→ F で決定。**テンションは明るめ、速さは標準、機械感は文末と読点の間で消す**。
- 読点の間を全部同じ長さにすると機械的に聞こえる（未決：文ごとに長さを変える案。70_beyond.md）。
- EQ：80Hz 以下カット、300Hz −2dB、3.2kHz +3dB（会場でこもらない）。
- クレジット「VOICEVOX:冥鳴ひまり」が必要。青山龍星は法人利用に事前連絡が要るので使わない。

## 7. 音（ミックス：scripts/30_mix.py）

| 項目 | 値 | 理由 |
|---|---|---|
| 基準 | 各ナレ行を −20 LUFS（VO_REF）にそろえてから並べ、最後に全体を −24 LUFS に移す | 行ごとの大小をなくす |
| ナレの測り方 | **2チャンネルにしてから測る** | モノラルで測って +3dB の誤差、BGM が常に3dB低かった（v4.7 で発見） |
| BGM（ナレ中） | VO_REF −16.5dB ＋ 声の帯域 1〜4kHz だけさらに −4dB | QC の「ナレ−BGM ≥15dB」を守りつつ、曲を痩せさせない |
| BGM（すき間） | VO_REF −8dB まで上げる。上げきって0.25秒以上保てるすき間だけ | 短いすき間で上げ下げすると落ち着かない。上限を付けすぎると平板 |
| 曲の大きさの測り方 | 区間の**平均**（90%点は大きく見積もって下げすぎた） | |
| 下げの始まり | ナレの0.35秒前から。戻しは0.10秒後から0.35秒。1.2秒より短いすき間はつなげる | 手書きのキーフレーム。サイドチェインは使わない（ポンピング） |
| 言い終わった後 | 声の帯域の削りは残したまま、1.0秒かけて +6dB 戻す。曲のフェードは画の黒より0.45秒早く始める | 減衰中の和音を急に持ち上げると「ふくらむ」。短いフェードは「切った」と聞こえる |
| 環境音 | 実写で VO_REF −21.5dB、図解でさらに −10、タイトル −6、エンドカードの紙 −8 | ナレより約20dB下 |
| 効果音 | 0.4秒窓の最大を VO_REF 比で：章扉の灯り −12、照準 −9、測距 −10、点が決まる −8。地図を描く鉛筆の音 −26（90%点） | ナレより大きくしない |
| 効果音の選び方 | **声の帯域（1〜4kHz）の外にエネルギーがある音**（鉄琴・電子音） | 自作の合成音は声と同じ帯域で、ナレ中に聞こえなかった（v4.6） |
| 仕上がり | −24 LUFS ±1、True Peak ≤ −2 dBTP、48kHz ステレオ、AAC 320k。ステムの和＝ミックス | 全パートで同じ値 |
| 切れ目 | すべてに10ms以上のフェード | プチノイズ |

### 曲の編集（scripts/34_prep_bgm.py）
- 小節の頭でだけ切ってつなぐ。等パワーのクロスフェード60ms。v4.10 は曲の1〜12小節＋25〜36小節、つなぎ目は D2 の段の変わり目（30.336秒）に隠す。
- 曲の終わりは、本来の終止を使う。フレーズの途中でフェードアウトしない。最後の和音は3秒のばす（55.0秒から、0.4秒で重ねる：`bgm.hold`）。和音が鳴っているうちに切らない。
- 曲の地図（小節ごとの強さ・楽器）を先に作る（scripts/41_bgm_structure.py、analysis/plan/bgm_01_new_departure.md）。

## 8. 検査の決まり（scripts/40_qc.py、docs/07 §1）

- 仕様（1920×1080、30000/1001、H.264 yuv420p、AAC 48k 2ch、尺±0.1秒、映像と音の長さの差≤0.1秒）
- 黒（0.1秒以上、と1コマだけの黒）、意図しない静止、焼き込みテロップの漏れ、点滅（1秒3回まで）
- 文字の表示時間（実測。**0件は FAIL**）、ラウドネス、ナレ−BGM ≥15dB（5パーセンタイルも）、クリック、言葉と画の同期 ±0.3秒、カットが拍にあるか、【要監修】の数、台帳に素材が載っているか
- 目視用：0.5秒ごとのコンタクトシート、文字ごとの3コマ＋等倍の小窓、絵コンテとの比較、`hyperframes snapshot --review`、ステムのラウドネスの推移
- **自分でシートを見てから**独立レビューに出す。
