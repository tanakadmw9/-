# 担当レビュー（チームで磨く）の指示文

使い方：版を1つ決め（例 v4.10）、担当ごとに**別のセッション**を立てて「共通ブリーフ」＋「担当の段」を渡す。担当はリポジトリを読むだけで、書くのは `reviews/<版>/<担当>.md` だけ。全員がそろったら、監督のセッションで prompts/30_director_synthesis.md を使う。

今回（v4.6 → v4.7）の実例：reference/plans/brushup/（director_team/00_BRIEF.md が共通ブリーフ）。

---

## 共通ブリーフ（全担当に渡す。【　】を埋める）

```
家族参観ミニシアター（建設コンサルタント会社）で上映する、測量部門のうち「【基準点測量】」1作業を伝える約【61】秒の映像を、チームで磨きます。
観客：専門知識ゼロの家族（子ども・年配者を含む）。大画面・会場スピーカー。
前提：このパートは部門の複数の作業の1つ。会社全体の意味は背負わない。

見るもの：
- 書き出し：【renders/draft/v4.x.mp4】、目視用シート：【qc/v4.x/*.jpg】、QC：【qc/v4.x/report.md、levels.png】
- 計画（承認済み）：【plan/content.md、plan/editing.md】（例は reference/plans/）
- 原稿：comp/narration.json、タイミング：comp/timeline.json（shots・vo・se・scenes・beats）
- 規定：docs/01、04（§8 やってはいけないこと）、05、07。決定記録：docs/decisions.md の直近。前回の独立レビュー：【qc/v4.x/review.md】
- 事実確認メモ：reference/research/kijunten.md
- 未決事項：【　】

制約：
- 実写は約40秒の焼き込み入り完成品だけ。新しい撮影なし。スロー・水増しなし。尺は24小節の格子が基本。大きく伸ばす案は別案として出す。
- 動画は画像で、音は数値（ffmpeg・numpy）で判断する。聞こえ方の最終判断は人。
- リポジトリは読むだけ。自分の作業ファイルは work/<担当>/ に。画像は読みすぎない（シート優先）。

返すもの（reviews/<版>/<担当>.md）：
1. 今の良い点（壊してはいけないもの）3つ以内
2. 改善案の表：| ID | 優先度（A=必ず／B=やると良い／C=余裕があれば） | 時刻 | 問題 | 具体的な直し方（数値・文言・秒・拍） | 理由 |
3. 対抗案（あれば）から取り入れられるもの
4. 【要監修】に足すもの、依頼者に選んでもらうこと（選択肢つき）
```

## 担当の段（共通ブリーフの後に1つ足す）

### 構成・技術監修役
```
あなたは構成と事実の担当です。家族が「何の仕事か」「どうやって位置が決まるか」「部門の中でどんな役か」を、この順でつかめるかを見てください。
用語が出る瞬間に何が映っているか（子どもは最初に見た物を言葉に結びつける）、たとえ（目印・ものさし・住所）が誤解を生まないか、図解の幾何が実務と矛盾しないかを確かめ、【要監修】を挙げてください。
```

### 編集
```
あなたは編集担当です。カットが小節・拍（の1コマ前）に乗っているか、曲の山と画の山が合っているか、静止・寄り・つなぎ（ディゾルブは1か所だけ）に理由があるか、図解の連続が長すぎないかを見てください。
語ごとのナレの時刻と画の出の時刻を実測し、ずれを表にしてください（言葉の0.3〜0.5秒前に画）。
```

### デザイン（モーショングラフィックス／アートディレクター）
```
あなたはデザイン担当です。docs/04 に照らして、文字（大きさ・表示時間・位置・改行）、図解の色の意味と記号、動き（同時に動くのは1か所、0.1〜0.2秒ずらし、バウンスなし）、照準（人の体に止めない・通さない）を見てください。
一つの意味が一つの瞬間に出ているか、急いで見える所がないかを、コマ単位で示してください。
```

### ナレーション演出
```
あなたはナレーション演出の担当です。原稿の一文ごとに「何のために言う文か（intent）」を書き、読み方（速さ・高さ・抑揚・立てる語・前の間・文末：soft／firm／cont）を提案してください（comp/narration.json の vv_dir の形）。
読み・アクセントの誤り（vv_kana）、読点の間の機械的なそろい方、尺の約7割を超えないかを確かめ、原稿の全文案（字数と推定秒：字数÷5.5、実測は1.1〜1.4倍）を出してください。
```

### 音響
```
あなたは音響担当です。audio/mix/ のステムと keyframes.json、qc の levels.png を測って、ナレと曲の差（ナレ中15〜18dB、すき間で6〜8dB）、曲の測り方（平均か）、効果音が声の帯域（1〜4kHz）とぶつかっていないか、言い終わった後と曲の終わり（和音を切っていないか）を見てください。
直す案ごとに、試聴用の mp3（同じ区間の今と案）を work/sound/ に作ってください。
```

### 正確さ監修（事実の担当を分けるとき）
```
あなたは用語と正確さの監修役です。reference/research/kijunten.md と docs/12_kanshu.md をもとに、画面とナレのすべての事実の表現を確かめ、
「壊してはいけない正確さ」「新しい指摘と修正案」「ほかの担当の案への監修意見」「測量士への質問（選択式）」「上映後に家族に聞かれそうなことと答えの例」を出してください。
```
