# 水準測量パート 内容計画 v6「ふたりで描く、道の横顔」

2026-10-29　監督。v5「見えない水の面」をやめて根から作り直した（理由は plan/rethink_v6.md §1）。
決め方：v5 を見ていない別のセッション2つ（人が主役／シリーズとしくみ）が4案、監督が2案。作者を伏せた比べ（reviews/concepts_v6/comparison.md）で、3つのセッションが別々にたどり着いた「道の横顔」を芯にし、人が主役の案の看板の動きと手帳を移した。

## 0. このパートの役目

**運ぶもの（1文）**：水準測量は、測量部門の中で「高さ」を受け持つ作業。**ふたりで一本の水平な線をつくり、そこから地面までをはかって、道の“横顔”を描く。**

背負わないもの：まちや暮らし全体の意味、海からの高さ・国の高さのしくみ、下水や水の流れ、往復の許容差、道の設計そのもの（設計は「道をつくる人」の仕事と言い分ける）。

**持ち帰る言葉（3つ）**
1. 「**ふたりで、地面の高さをはかる**」
2. 「**まっすぐな線から、下までをはかる**」
3. 「**つなぐと、道の横顔になる**」

**締めの一文**：「**ふたりで、道の“横顔”をはかる。それが、水準測量です。**」（画面の文字は「道の “横顔” をはかる」）

**シリーズの中の位置（一言）**：1本目は**真上から見た「位置」**、2本目は**真横から見た「高さ」**。

| | 1本目 基準点測量 | 2本目 水準測量 |
|---|---|---|
| はかるもの | 位置（どこ） | 高さ（どれだけ上か下か） |
| 看板の動き | 写真が**奥へ倒れて**真上の図。人が消え、**点が残る** | 写真の**奥行きがたたまれて**真横の図。**人が残り**、二人が同じ大きさで並ぶ |
| 形の合図 | 点（照準＝十字＋円） | 線（水平な点線）。照準は使わない |
| 目印の形 | 紺の △ | 紺の □ に点（地図の水準点の形）【要監修】 |
| 結果 | 地図や道路の図面の「はじまりの点」 | 道の「横顔」 |
| 締め | ほかの測量が使う “はじまりの点” | ふたりで、道の “横顔” をはかる |

## 2. 案の比較

### 2.1 中心の絵：**道の横顔**
- 絵：紙に横線を1本。その下にでこぼこの地面。線から地面まで棒を何本かおろし、棒の先をつなぐと、**道を真横から見た形**が出てくる。棒をおろすのは、**ものさしを持って歩く人**。
- 子どもが家で言うこと・描くこと：「まっすぐの線から下までをはかって、つなぐと道の横顔になるんだよ。ものさしを持った人が歩いて描くの」。紙と鉛筆で再現できる。

### 2.2 なるほど（1つ）
- 見る前：道は平ら。高さは、下から上へものさしを当ててはかるもの。
- 見た後：**高さは、空中の一本の水平な線から“下へ”はかる。だから、つなぐと、平らに見えた道の横顔（ゆるい上り下り）が出てくる。**
- 「長いほど低い」はその途中の一歩。クイズにせず、棒の長さと文字で約2秒見せるだけ。

### 2.3 看板の動き：「奥行きがたたまれて、真横になる」
K の二人が一画面のコマ（観測者が右手前でかがんでのぞき、標尺手が左奥に小さく立つ）を止め、線でなぞり、写真を紙に溶かし、**奥行きをたたんで真横の図にする**。斜めに奥へ走る縁石の線が画面下3分の1のまっすぐな地面になり、**遠くで小さかった標尺手が、観測者と同じ大きさまで大きくなって**左に立つ。望遠鏡から水平な点線が標尺へ。線から地面まで紺の棒（読み）。
- 1本目との違い：倒れる（X 軸）⇔たたむ（遠近をなくす平らな変形）。残るものが点⇔人と線。回転の汎用トランジション（rotateY）は使わない（docs/04 §8 の「汎用トランジション」に見えるおそれ）。
- 試作で先に確かめる：なぞりの品質（切り絵・AIっぽく見えないか）。外形は SVG のパスとして部品に持ち、線の太さと描く速さをそろえる。

### 2.4 尺：28小節（70.8秒）をおすすめにする理由
- 考えを5つに絞ったので、91秒を埋めるには往復・くり返し・2本の差が要り、どれも v5 の骨組みを呼び戻す。
- 使える実写は約40秒。81〜91秒では「のぞく・書く」のくり返しでゆるむ。28小節なら実写約6割、図が続くのは最長約8秒。
- 1本目（60.7秒）より約10秒長い分は「坂が決まる」の1拍と、顔の間。91秒（1本目の1.5倍）より並べたときに自然。
- 曲：元の1〜16小節＋25〜36小節（つなぎ目1か所。17〜24は9〜16のくり返しなので目立ちにくい）。依頼者が選んだ M1d の「止め」をどこかに使うかは編集計画で試し、聞き比べで出す。

### 2.5 本気の別案「ふたりの一本線」（2番手）
- 芯：二人のあいだの真横の線で高さを読み、近くの水準点から**工事の場所の高さの目印（仮BM）まで高さを運ぶ**。看板は同じ「遠くの人が同じ大きさになる」。持ち帰る言葉「ふたりで高さをはかる／真横にのぞいてものさしを読む／高さを工事の場所まで運ぶ」。締め「のぞく人と、持つ人。ふたりで、高さを運ぶ。それが、水準測量です。」
- これに替えるとき：①部門が「道の横顔（縦断）は路線測量パートのもの」と言った ②素材の現場が仮BM の設置だとわかった。
- 1番に負ける理由：中盤が v5 と同じ骨組み（後ろ−前の差、尺取りで運ぶ）。「高さを運ぶ」は子どもの絵にならず、出口も家族の物にならない。
- 比べた他の案（reviews/concepts_v6/comparison.md）：「手で書いた数字が、道になる」17点相当（手帳の1カットだけ移した）／「高さのバトン」15点相当（引き算と往復が v5 と同じ）。

## 6. 決めてほしいこと（5問以内、おすすめ ◎）

1. **部門に一問**：水準測量のパートで「道の横顔（縦断）」を見せてよいか。路線測量のパートはあるか。
   - ◎ 見せてよい → このまま
   - 路線測量パートがある → 横顔は「描いて渡す」まで。B9 の新しい道の線を描かず、横顔が路線のアイコンへ流れて灯る。締めは「道をつくる人が使う、“道の横顔”をはかる」
   - 縦断は路線パートが見せる → 別案「ふたりの一本線」（§2.5）に替える
2. **締め**：◎ (a)「ふたりで、道の“横顔”をはかる。それが、水準測量です。」／(b)「真上から見ると、位置。真横から見ると、高さ。それが、水準測量です。」（1本目と続けて上映するなら強い）
3. **長さ**：◎ 28小節 70.8秒／32小節 80.9秒（顔と歩きの間を1拍足す）。91秒は中身が足りなくなるので、おすすめを替える
4. **曲の編集**：聞き比べで出す（編集計画）。止めを使う版／使わない版
5. **撮り足し（5分、前提にはしない）**：標尺手の顔と、ものさしを両手で立てる手の寄り。頼めれば B4 か B10 に入れ、「うちの人が映っていない」をなくす

## 7. 【要監修】（測量士に確かめる）

1. 素材の現場の作業は、仮BM の設置か、縦断測量か（答えで §6 の1が変わる）。
2. 「機械がつくるのは、まっすぐ水平な、一本の線」（自動レベルの視準線）。
3. 「その線から、地面までの長さを、ものさしで読みます」「地面が低いところほど、長く読めます」。

8. 班を「ふたり」と言ってよいか（記帳・交通誘導の人がいる場合）。出演の二人の上映の了解。

## 8. この計画の弱点（本気で）

1. **路線測量パートとの取り合い**（§6 の1）。部門の答えで芯が変わる。
2. **物理は v5 と同じ**（水平な線から下へ。長いほど低い）。依頼者が「また水平な線か」と感じるおそれ。違いは、水という言葉を一度も出さない・クイズにしない・数字を出さない・線の出どころが「二人のあいだ」・結果の形（横顔）が中心、の5つ。ゲート報告で先に1行で言う。
3. **なぞりの品質**：K の標尺手は小さい（1.32倍でも約8画素幅）。なぞりは実写の上で最初の0.3〜0.8秒だけ重ね、すぐ図の中で大きくする。雑なら「切り絵」に見える。承認の後すぐ試作で確かめる。
4. **標尺手の顔がない**。撮り足しなしでは、二人目はずっと遠くの姿と歩く後ろ姿だけ。
5. **「立ち替わり3回」は素材にない**。素材には標尺手が1回歩く所（S 168）しかなく、図が人の動きを補う。
6. **480p の S を4か所**（B2・B3・B6・B10）。早回しと 1.25倍以内でしのぐが、大画面で甘く見える。
7. **「坂が決まる」は設計の話に1歩入る**。主語を「道をつくる人」にして踏みとどまるが、測量士に言い過ぎと言われたら N11 を「坂のかたむきを決める、もとになります」に下げる。
8. **長さを替える**：依頼者は約91秒を選んだ。中身に合わせて70.8秒をすすめ直すので、理由を短く言う必要がある。
