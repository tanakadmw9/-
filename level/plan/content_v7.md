## 1. このパートの役目

**運ぶもの（1文）**：水準測量は、測量部門の中で、ほかの測量や工事が使う「**高さの目印**」をつくる作業。高さのわかっている目印から、水平な目線を通して、となりへ、となりへと高さを運ぶ。

背負わないもの：海からの高さ・国の高さのしくみ、下水や水の流れ、まち全体の安全、道の設計そのもの。

**持ち帰る言葉（3つ。どれも声で言う）**
1. 「**高さの目印をつくる**」（N2・N15）
2. 「**高さが、のぼって、わたって、おりる**」（N6。手で再現できる）
3. 「**その目印をもとに、道がつくられる**」（N12）

**締めの一文**：「**ほかの測量や工事が使う、“高さの目印”をつくる。それが、水準測量です。**」（1本目「ほかの測量が使う “はじまりの点”」と同じ組み方）

**シリーズの中の位置**

| | 1本目 基準点測量 | 2本目 水準測量 |
|---|---|---|
| つくるもの | 位置の目印 | 高さの目印 |
| しくみ | 角度と距離で、点の位置が決まる | 高さが、うしろのものさしをのぼり、水平な目線をわたり、まえのものさしをおりる |
| 看板の動き | 写真が奥へ倒れて真上の図。人が消え、点が残る | 写真の奥行きがたたまれて真横の図。人が残り、遠くの人が同じ大きさで並ぶ |
| 目印の形 | 紺の △ | 出発は紺の □に点（地図の水準点）。新しい目印は □（点なし）【要監修】 |
| 使われる先 | 地図や道路の図面 | 道をつくる工事 |

## 2. 中心の絵と、なるほど

### 2.1 中心の絵：**高さが、のぼって、わたって、おりる**
- 真横から見た図。右に「高さのわかっている目印」（紺の□に点）と、その上のものさし（うしろ）。左に、これから高さを知りたい所と、そのものさし（まえ）。まんなかに機械。機械の目線は水平な一本の線。
- 高さのしるし（オレンジの小さな丸）が、□から**うしろのものさしを目線の高さまでのぼり**、**水平な目線をわたり**、**まえのものさしをおりる**。おりた所が、まえの地面の高さ。おりる長さがのぼった長さより長いので、何も言わなくても「まえのほうが低い」が見える。
- 子どもが家でやること：右手の指でものさしをのぼり、まっすぐ横にわたって、左でおりる。「高さは、のぼって、わたって、おりて、となりへ運ぶんだよ」。
- 数字は出さない。引き算もしない。「長ければ低い」も声で言わない。

### 2.2 なるほど（1つ）
- 見る前：高さは、その場で地面にものさしを当てればはかれる。
- 見た後：**ミリまで正しい高さは、わかっている目印から、のぼって・わたって・おりて、となりへ運んでくる。**

### 2.3 看板の動き：「奥行きがたたまれて、真横になる」
K の二人が一画面のコマで止め、外形をなぞり、紙に溶かす。
1. 観測者はそのまま、遠くの標尺手だけが観測者と同じ大きさまで大きくなる。
2. 全体が引いて真横の図に収まる。まえのものさし x 640、機械 x 1180、うしろ x 1720。**機械は二本のまんなか**に置く（前後の距離をそろえるのは水準測量の大事な工夫）。
3. 右に□とうしろのものさしが、紙から描き起こされる。標尺が1本の班なら、点線の外形にする（＝さっき読んだ所。§7 の1）。
4. 観測者が三脚のうしろを通って機械の左へ回り、うしろ向きにのぞく。うしろへの目線がその場で現れる（紺、のびない）。□が灯る（「目印」）。
5. 「高さが」で、□の光から**高さのしるし**（オレンジの小さな丸）がふくらんで生まれる。**のぼって**：うしろのものさしを目線の高さまで（通った所にオレンジの細い跡を残す）。**わたって**：目線を機械まで来て、**機械の中で光って止まる**（機械が高さを持つ＝器械高）。その間に観測者が三脚のうしろを通って機械の右へ回り、まえへの目線（オレンジ）が現れる。続けて目線の残りをわたる。
6. **おりる**：まえのものさしをおりる（「おりる」の前に 0.15 秒の間）。段差が光る。跡はコの字に残る。

決まり：
- 目線は「その場で 0.3 秒で現れる」。端からのばさない。当たる所に音を付けない（光線に見せない）。
- 一度に動くのは1つ。文字も一度に1つ。

   - 試作で B8 を短くする案と比べる。
