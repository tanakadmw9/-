## 3. 看板 fold_side と relay

### 3.1 作り方（v6.1 から引き継ぐ）
- `comp/compositions/fold_side.html`（B5）、`relay.html`（B7・B9）、`profile.html`（B10）。1920×1080 の SVG。
- 線は `<line>` の端点を `attr` で動かし、なぞりは `stroke-dashoffset` で描く。人・機械・ものさしは `<g>` を GSAP の `x`・`y`・`scale`・`autoAlpha` で動かす。
- rotateY と 3D は使わない。
- MorphSVG・MotionPath（`node_modules/gsap` の 3.15.0 にあるが、`comp/assets/vendor/` にはない）も使わない。印の山なりの渡りは、`{t:0→1}` を tween し、onUpdate で x＝線形、y＝足もと−高さ×sin(πt) を書く。
- 色：わかっている＝紺、新しい／いま読んだ＝オレンジ。目線の点線はオレンジ（6 px、18／12 の破線）。
- 動き：入りは power3.out 0.4〜0.6 秒、消えは power2.in 0.25〜0.35 秒、動きは power2.inOut。一度に動くのは1つで、ずらすなら 0.05〜0.2 秒。跳ねる動きは使わない。
- 点線は人の体（なぞった外形を含む）を通さない。鉄琴は「段差」「渡る」「灯る」だけに付け、線が当たる所には付けない（光線に見せない）。
