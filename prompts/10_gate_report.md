# ゲートで依頼者に出す報告の形

依頼者はスマホで見る。**短く、ファイルを添えて、決めてほしいことを先に。**

```

見るもの
- 映像：renders/draft/v4.10.mp4（60.7秒）
- 0.5秒ごとのシート：qc/v4.10/contact_0p5s_1of3.jpg ほか
- 監督メモ：（リンク）

決めてほしいこと（おすすめに◎）
1. N6 の言い方：◎「点がずれると、あとの測量もずれる。だから、何度もはかって確かめます。」／ 今のまま
2. 環境音：◎ 鳥＋草 ／ 今の風だけ ／ 田舎道
3. （5問まで）

比べるファイル
- 声・音の比較：audio_tests/N6_ABC.mp3 など

既知の問題
- 声は仮ナレ（VOICEVOX）。本ナレに替えたら時刻を合わせ直す
- 【要監修】が◯か所（docs/12_kanshu.md）。試写2で測量士に確認
```

## 決まり
- 決めてほしいことは5問以内。選択肢は2〜4つ、おすすめは1つ、それぞれ「選ぶとどうなるか」を一言。
- 好み（声・曲・色・間）は、比べられるファイルを必ず添える。
- 既知の問題は隠さない。自動QC の WARN と、独立レビューで据え置いた指摘を書く。
- 依頼者の答えは docs/decisions.md に「決めた人：依頼者」で記録する。
