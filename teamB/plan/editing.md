## 0. 要点（A案との違いはこの6つ）

1. **画は 2.39:1 のシネスコ。** 帯は上下138px、画は y138〜942（1920×804）。焼き込みテロップは帯の外へ逃がす。拡大は S01・S02 が1.06倍、ほかは**等倍**（A案は1.20〜1.41倍）。
2. **音が先、画があと。** 0秒は黒に風と鳥。曲は問いのあと（9.4秒の拾い音→10.8秒の小節頭でタイトル）。ナレ・音は画の切り替えより先に入れる（Jカット）。
3. **「はかる」で一度、すべての音が止まる。** 曲の4小節目の終わり（27.16秒）で曲を切り、1.5拍の無音の中で TS の「ピッ」だけ鳴らす。次の打楽器が入る一拍目（28.69秒）で画面が二つに割れて、しくみの説明が始まる。
4. **図解は実写に直接描く（合言葉「見えない線を見えるようにする」）。** しくみだけ分割画面（左＝人の実写、右＝紺の観測パネル）で1回。紙の別画面には一度も切り替えない。実写が画面から消えるのは最後の金属標と終わりの約16秒だけ。
5. **カメラの動きは2か所だけ。** S04 の止めのコマへのゆっくりした寄り（タイトル）、S10 の止めのコマへのゆっくりした寄り（地図の線）。どちらも、止めたことを感じさせないためだけに使う。
6. **最後は曲本来の一音で終わる。** 曲の24小節目の最後の一音（57.32秒）でエンドカード。そのあとの響き（約4秒）が消えるところで映像も終わる（61.5秒）。フェードアウトで逃げない。

## 2. 音楽：「緑色の木漏れ日」（ioni）の地図と編集

### 曲の計測（`analysis/bgm_03_komorebi.md`）

- 1拍 1.0227秒（58.7 拍/分）。1拍が3つに割れる、ゆったり揺れるリズム（細かい音は0.34秒ごと）。テンポは一定（ずれ最大16ms）。1小節＝4拍＝4.091秒、和音は2小節ごとに回る。
- 最初の拾い音は0.33秒、**1小節目の頭は1.356秒**。

| 曲の小節 | 曲の時刻 | 部分 | 特徴 |
|---|---|---|---|
| 1〜4 | 1.36〜17.72 | 前奏 | ギターだけ。打楽器なし（−31dB） |
| **5** | 17.72 | **A の頭** | **打楽器が入る**。曲でいちばんはっきりした変わり目 |
| 5〜12 | 17.72〜50.45 | A | 2小節ごとの同じ形 |
| 13〜16 | 50.45〜66.81 | B | 和音が変わるひとまとまり |
| 17〜20 | 66.81〜83.17 | A（くり返し） | 20 は次へのつなぎ |
| 21〜23 | 83.17〜95.44 | 終わり | 打楽器が抜け、前奏に近い静けさ |

- 音質：12kHz より上が切れている（96kbps）。会場の小さなスピーカーでは差が出にくい帯域だが、曲を前に出す所（タイトル、最後の一音）は大画面の試写で確かめる。

### 編集（つなぎ目1か所＋「間」）

**曲の 0〜17.72秒（拾い音＋1〜4小節） → 無音1.53秒 → 5〜6小節 → 19〜24小節**

| 映像の時間 | 曲 | 画 |
|---|---|---|
| 0.00〜9.44 | なし（環境音と足音だけ） | コールドオープン、問い |
| 9.44 | 拾い音（曲の0秒） | 間①の終わり。ギターが静かに入る |
| **10.80** | 1小節目の頭 | **S04＋タイトル**（答え） |
| 10.80〜27.16 | 1〜4小節（ギターだけ） | タイトル、S01、S03、S09 の動き |
| **27.16〜28.69** | **無音（1.5拍）** | S09 が止まる。**「ピッ」だけ**が鳴る |
| **28.69** | **5小節目＝打楽器が入る** | **分割画面が開く** |
| 28.69〜36.87 | 5〜6小節 | しくみ（観測パネル4段） |
| **36.87** | **つなぎ目：曲の6小節目の終わり→19小節目の頭** | 分割画面→S10 の切り替え（画の変化でつなぎ目を隠す） |

- つなぎ目の候補を数値で比べた（`analysis/splice_cost.txt`、小さいほど自然、0＝本来のつながり）。**6→19 は 26**（2番目に低い）。曲の 17〜20 は 5〜8 のくり返しなので、6の次に19が来ても「同じ形の続き」に聞こえる。次点：5-6-7-8-20（66）、5-6-18-19-20（65）。いちばん低い 9→20（12）を使う並びは尺が66秒になり、実写が約9秒足りなくなるので不採用。
- 「間」は本来のつながり（4→5）を無音で引き離すだけなので、つなぎ目の不自然さは生まれない。曲は 0.3 秒かけて切り、5小節目は30ms前から入れる（頭の一打を欠かない）。
- 曲の入りを内容担当の推す「答え（タイトル）」にしたのは、0〜25秒を曲なしにすると子どもには長い（content.md §2）ため。曲が「はかる」まで黙っている案より、**「問いには音がない、答えると音楽が鳴る、はかる瞬間にまた止まる」**という一貫した決まりになる。

## 4. リズムの決まり

- **問いには曲がない、答えると曲が鳴る、はかる瞬間に曲が止まる。** 音の有無そのものを語りに使う（このパートの編集のこだわり）。
- 場面の変わり目は小節の頭（10.80、28.69、36.87、45.05、57.32）。場面の中のカットと AR の段は拍の頭。曲のない冒頭10.8秒だけは足音と動作に合わせて切る。
- ナレは画の変わり目から0.3〜0.5秒遅れて入る。ただしタイトル（N2）は小節頭より0.7秒前から入れて、「住所」の言葉を小節の頭に重ねる。
- 意味の山：「住所」＝タイトルが出る小節頭、「基準点」＝ラベルの拍、「ピッ」＝無音の中、「決まります」＝鉄琴の拍、最後の一音＝エンドカード。

## 5. AR（実写の上に描く）と分割画面の動き

**描き方の決まり**

- 地面の上の点は**地面に寝かせた楕円**で描く（真上から見た丸を、カットの奥行きに合わせてつぶす）。画に「置いてある」ように見せるため。カメラがほぼ固定のカットにだけ描く（S02 の指先、S01、S10 の止め）。動くカットには描かない（追従のずれが出るため）。
- 線は白3〜5px、琥珀は4〜6px、端は丸く。明るい草の上で線が消えないよう、線の下に**半透明の濃い縁**（線より4〜5px太い、不透明度50%）を1本だけ敷く。影やグローは使わない。
- 一度に動くのは1つ。入り0.5秒 power3.out（線は描き進める、点は0.3秒で広がる）、出0.3秒 power2.in。点滅は1秒に3回以下（光の往復は1往復0.5秒）。
- 実写の上のラベルは6字以内、44px、濃い板（不透明度78%）。説明の文は帯の中に置く。

## 9. 内容プランへのお願い（ナレの調整）

## 11. 残るリスク

- 曲は96kbps。タイトルと最後の一音で曲を前に出すので、大画面・会場のスピーカーで確かめる。
- AR は手で位置を決める。S01・S10 はほぼ固定だが、元のカメラにわずかな揺れがあるので、書き出したフレームで楕円が地面から浮いて見えないか確かめる（必要なら位置を数コマごとに打つ）。
- 金属標の線画は、それまでの実写と質感が大きく変わる。輪が広がって外形になる動きで「同じ点」とつなぐが、試写で唐突に見えたら、S03 の草の画を暗くして下地に敷く案に替える。
- 冒頭10.8秒は曲がなく、ナレも1文だけ。年配の観客に長く感じられたら、間①を2.5秒に詰める（曲の拾い音を早める）。
- 本ナレ（社員の声）に替えて読みが遅いと、N9・N10 が最後の一音に間に合わない。その場合は N10 を最後の一音の上に重ねる（響きの上で終わる）か、原稿を短くする。
