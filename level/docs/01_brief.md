# ブリーフ — 水準測量（レベル）パート（v8.5、2026-10-30）

- 上映：建設コンサルタント会社の家族参観ミニシアター。測量部門のシリーズの2本目（1本目＝基準点測量）。大画面＋会場スピーカー。
- 観客：社員の家族（専門知識ゼロ、子ども・年配者を含む）。
- 長さ：**28小節＝70.8秒**（曲 V6b の組み方）。尺の幅はシリーズのブリーフ（リポジトリの `docs/01_brief.md`「尺：60〜80秒」）に従う。32小節（80.9秒）は上限をこえるので別案。
- この現場：道路を**設計するため**の測量。水準点はつくらない。高さは、近くに決めた目印を基準にする（公共の水準点につなぐか、設計上の仮の高さ。測量士の答えが来るまでは仮の高さとして組む）。行きと帰りで確かめる。
- 運ぶもの（一文）：高さは、ひとつの基準からはかる。日本は海を0にし、道路を設計する現場では近くの目印を基準にして、そこから高さをミリまでつなぐ。はかった高さは、位置とあわせて、道路の設計に使われる。
- 持ち帰る言葉：「高さは、ひとつの基準からはかる」「現場では、近くの目印からはかる」「位置とあわせて、道路の設計に使われる」。
- 締め：「設計が使う、“高さの土台”をはかる。それが、水準測量です。」
- 前のパートとの対：基準点測量＝位置の目印（はじまりの点）、水準測量＝高さの土台。
- 背負わないもの：会社全体の意味、工事の話、国の高さのしくみ（N4 の一文だけ）。海と現場は「ひとつの基準からはかる」という考え方でつなぎ、線でつながない。0 は海にだけ使う。
- 声で言う専門用語は「水準測量」の1つだけ。レベル・標尺は画面のラベル。
- 素材：社内の実写3本（約3分＋25秒＋13秒）。外部に送らない・公開しない。
- 正本：内容は `plan/content_v8.md`、秒は `plan/editing_v8.md`。
