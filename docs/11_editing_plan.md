## 0. 要点（この5つで全体が決まる）

1. **尺は24小節＝60.7秒に固定する。** 曲（New Departure、94.9BPM、1小節2.528秒）の小節を時間のものさしにし、場面の変わり目は小節の頭、場面の中のカットは拍に置く。ナレの長さから尺を決める今の作り方（v4.x）をやめ、**拍の格子にナレを収める**作り方に変える。
2. **曲は1か所だけでつなぐ。** 曲の1〜12小節＋25〜36小節。つなぎ目は図解 D2 の段が変わる瞬間（30.3秒）に隠す。v4.4 で気になった0:41のつなぎ目はなくなる。
3. **曲の山と画の山を合わせる。** 8小節目＝曲の「息つぎ」に「基準点」の定義、9小節目＝全楽器が入る一番強い頭に「はかる」実写、21小節目＝曲の最後の一打に締めの実写。最後の一打のあとの約9.5秒の伸ばしが、そのまま余韻とエンドカードになり、映像の終わりで自然に消える（フェードアウトしない）。
4. **動きは「理由があるところ」の3か所だけ。** タイトルの静止画への寄り、最後の S10 への寄り、D1→D2 の「実写が倒れて真上の図になる」動き。ほかの実写は素のまま（元のカメラの動きを活かす）。
5. **この1本を部門の全パートの型にする。** 章扉（作業アイコンの列）、タイトルの組み方、ラベル、締めとエンドカード、効果音、ラウドネスを共通部品にし、24小節の骨組みをほかの作業パートでも使えるようにする（§11）。

## 4. リズムの決まり

- **場面の変わり目＝小節の頭**、場面の中のカット＝拍の頭。拍から外れたカットは作らない（自動チェックで検査する）。
- 映像のカットは拍の**1コマ前**に置く（目は耳より先に変化を感じるので、拍とぴったり合って見える）。
- ナレは場面の変わり目から0.3〜0.5秒遅れて入る（画を見てから聞く順にする）。ナレの頭を小節の頭の強い音にぶつけない。
- 意味の山は拍に置く：「ひとつ、」＝章扉のアイコンが灯る拍、「基準点測量」＝照準が合う拍、「決まります」＝14小節頭の点が打たれる拍、「はじまりの点」＝締めの文字が出る拍。
- 本ナレ（社員の声）に差し替えて長さが変わっても、**格子（小節）は動かさず、ナレの置き場所を拍単位で直す**。収まらない文は原稿のほうを直す。

## 5. カメラの動き（デジタルの寄り・パン）

docs/04 §6・§8 に従い、全カットに同じ動きはかけない。使うのは次の3か所だけ。

| 場所 | 動き | 理由 |
|---|---|---|
| B1 S04 の最後のコマ（約1.9秒の静止） | 毎秒2%以下で中心のプリズムへ寄る | 静止を感じさせず、照準へ視線を集める |
| B8 S10（約3秒） | 毎秒1.5%で寄る（1.20倍→約1.25倍） | v4.4 の「最後の画が止まって見える」への対応。見渡す先へ気持ちを運ぶ |
| D1→D2 | 静止した実写が奥へ倒れ、真上から見た図になる（約1.0秒、power2.inOut） | 「同じ場所を上から見ている」ことを動きで理解させる |

- S01・S02 は既に1.41倍なので、それ以上の拡大はしない。
- 揺れの補正（スタビライズ）はしない（圧縮素材で端が崩れる）。S07 の手持ちの揺れは人の気配として残す。

## 8. 図解の動き

全体：紙の背景＋うすい方眼、既知＝紺の△、新しい＝オレンジの◎、光の線＝オレンジ。入り0.4〜0.6秒 power3.out、出0.25〜0.35秒 power2.in、一度に動くのは1か所。

| 図解 | 動き（拍） | 再利用 |
|---|---|---|
| **章扉**（新規・共通） | 1拍目：紙と方眼が出る → 2拍目：アイコン5つが左から0.1秒ずつ出る → 3拍目：基準点のアイコンだけオレンジに灯る（効果音④）→ 4拍目：灯ったアイコンが照準に変形しはじめ、S04 へ | 作業ごとに「灯る位置」だけ変える |

| D1 | 静止した S09 の上に TS とプリズムの点→ラベル→光の線が2往復（「角度」「距離」の言葉で） | v4 の D1 を継続 |
| D2 | 倒れて真上の図 → 12小節：角度の弧 → 13小節：距離の線 → 14小節頭：新しい点Pが打たれる（効果音③） | v4 の D2 から座標の数字を外す |
| **点つなぎ**（新規） | D2 の P が地図の紙の上の1点になり、引くと基準点が数個 → 18小節：等高線がすっと描かれる → 19小節：道路の中心線 → 20小節：上から章扉のアイコン列が下り、基準点アイコンから地形・路線のアイコンへ線がのびて灯る | 構成は内容プラン §5 |
| エンドカード | S10 の最後のコマの上で照準が縮み、章扉の基準点アイコンの位置・大きさに戻る | 共通（灯るアイコンだけ変える） |

## 9. 色

- 方向は v4 の色補正案 B を継続（緑を少し下げ、わずかに暖かく、黒を少し締め、ハイライトを抑える）。最終は試写で決める。
- **先にカットどうしをそろえる**。基準は S01・S07（明るさ50前後、暖かさ20前後）。
  - S02・S04・S10（明るく冷たい、空が白い）：露出を少し下げ、暖かさを足し、ハイライトを丸める（白飛び部分の縁をなだらかに）。
  - S06・S08（暖かすぎ）：暖かさを少し引く。
  - S09：冷たいので暖かさを足す。D1 の静止画は同じ補正のまま使う（図解と実写の色を切り替えない）。
- 強い補正はしない（圧縮素材でバンディングが出る）。シャープは足さない。空にデバンド、全体にごく薄いグレイン。
- 図解の紙（#F4F1EA）と実写の明るさの差が大きいので、S08→地図のディゾルブは紙の明るさを実写の空に合わせてから溶かす。

## 10. 音のミックス

| 層 | 決まり |
|---|---|
| ナレ（主役） | 全体 −24 LUFS（±1）、True Peak −2 dBTP 以下に合わせる基準。帯域1〜4kHzをほかの音でふさがない |
| BGM | ナレ中はナレの約15〜18dB下。ナレがない所は6〜8dB下まで上げる。下げはナレの0.3〜0.5秒前から（手で書いた音量変化） |
| BGM の見せ場 | ①章扉〜タイトル（ナレ N1 の前後）、②8小節の息つぎ（自然に薄くなる）、③9小節頭の強い一打（N4 の前に0.4秒だけ開ける）、④21小節の最後の一打（N8 の前に0.4秒だけ開け、伸ばしの上で N8） |
| 環境音（風・草・遠くの鳥） | 実写の区間だけ、ナレの約20dB下。図解に入ると0.5秒で −10dB 下げ、実写に戻ると戻す。終盤は v4.4 より −4dB |
| 効果音（4種類まで） | ①照準が合う「ピッ」：2小節3拍（タイトル）と、エンドカードで照準が戻る瞬間（小さめ）＝**シリーズ共通の合図** ②測る短い電子音：D1 の光の線 ③点が決まるクリック：14小節頭（新しい点）、20小節（アイコンが灯る、小さめ） ④章扉でアイコンが灯るやわらかい音：1小節3拍。どれもナレより大きくしない |

- 曲のつなぎ目（30.3秒）は 60ms で重ね、D2 の「距離」の線が伸びはじめる瞬間に置く（耳の注意が画に向く所）。
- ステムはナレ／BGM／効果音・環境音の3本を書き出す。

## 11. シリーズ共通の型（ほかの作業パート用テンプレート）

**骨組み：24小節（約60秒、曲が95BPM前後の場合）**

| 小節 | 役割 | 中身（作業ごとに入れ替える所） |
|---|---|---|
| 1 | 章扉 | 灯るアイコンの位置（アイコンは現場の順に 基準点＝三脚と▲／水準＝標尺／地形＝等高線／路線＝道路の中心線／用地＝境界杭【要確認：部門の実際】） |
| 2〜3 | タイトル | 作業名＋ひとことのサブ、背景の実写1カット |
| 4〜6 | 現場 | 人と道具の実写2カット |
| 7〜8 | 用語 | その作業の主役の物（基準点なら地面のしるし）を図解1つで |
| 9〜14 | しくみ | 実写→静止→図解の流れで、仕組みを1つだけ |
| 15〜17 | 人 | 確かめる・記録する人の実写 |
| 18〜20 | 部門の中での役割 | 章扉のアイコン列に戻り、ほかの作業とのつながりを線で |
| 21〜24 | 締め | 実写2カット＋締めの一文＋照準が章扉のアイコンに戻る |

**共通部品**（comp/ に1つずつ置き、パラメータだけ変える）

- `tokens.css`（色・文字・余白・動きの時間）
- `chapter_door.html`（アイコン列。`active` で灯る位置を指定）
- `title.html`（小見出し「測量部門のしごと」＋作業名＋サブ）
- `label.html`（点＋引き出し線＋紺の板）、`telop_keyword.html`
- `endcard.html`（照準が章扉のアイコンへ戻る。締めの一文とクレジット）
- 効果音①〜④、ラウドネス −24 LUFS / −2 dBTP、色補正の基準（S01・S07 相当の明るさと暖かさ）
- `timeline.json` の作り方：曲の BPM と最初の拍から小節の格子を作り、場面は小節番号で指定する

**曲**：部門の全パートを続けて流すなら、曲の選び方（同じ曲を使い回すか、パートごとに変えるか）は部門全体で決める必要がある。この型はどちらでも成り立つ（前奏の1小節が静かな曲であること、最後に自然な終わりがあることが条件）。
