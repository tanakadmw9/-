# 計画の批評 v8.4（水準測量パート「海からの高さ」・設計のための測量）

2026-10-30。作り手とは別のセッションの批評。
- 対象：level/plan/content_v8.md（§0〜§4・§15 を正本、§5 以降は食い違いの確認）、level/plan/editing_v8.md、絵コンテ storyboard_v8_p1〜p3.jpg、level/docs/01_brief.md。対の確認に 1本目の原稿 comp/narration.json。

- 依頼者が示した事実（この批評の基準）：建設コンサルタント／道路の**設計**のための測量／水準点はつくらない／高さは**設計上の仮の高さ**として組む／往復で観測／1本目と対で「高さの土台」／観客は専門知識ゼロの家族。
- この版が治すべき依頼者の却下：①「日本の0が東京湾から、現場に高さの目印でそれ基準に、が結びつかない、モヤる」②「はかった高さをもとに道路の図面、はいいすぎ。高さだけじゃ図面できない」。
- 見る人：小3の子を連れた親、水準測量20年の測量士、映像制作会社のベテラン編集者。

## 先に結論

- **②（言いすぎ）は治った。**N10「はかった高さは、位置の測量とあわせて、設計の手がかりになります。」は事実として正しく、言いすぎていない。ただし「道路」が消えて家族に絵が浮かばず、B10 を 1.23 秒はみ出して言葉の途中でカットされる（M2）。
- **①（結びつかない）は、測量士には治ったが、子どもには治っていない。**
  - 測量士の目：「どちらも一つの基準からはかる」という対比は、仮の高さの現場でも公共の水準点につないだ現場でも正しい。海と現場を線でつながない決めも正しい。
  - 子どもの目：つなぎの芯「**同じ基準からはかるから、そろう**」が**声で一度も言われない**。声で言うのは「考え方は同じです」だけで、「考え方」が何かは子どもには取れない。画の韻（0 の線から棒／□ の線から棒）は、全画面のきれいな図と、2.6 秒後の街の写真の遠くの 40 px の □ で、大きさも見え方も違うので、気づかれにくい。音の韻（C6）も「同じです」ではなく、その 1.2 秒前の □ に鳴る。
  - つまり「モヤる」の原因（海の話と目印の話の間の“なぜ”）は、まだ「考え方は同じです」の一言に預けたまま。これは計画自身が弱点 8 で認めている。
- 持ち帰る言葉3が、前回直した「図面」から抽象的な「設計の土台」に戻った（項目1・7が下がる）。
- 点は **15/20**。16点未満なので、このままでは出さない。M1〜M4 で 18、M5〜M7 まで直して 19 の見込み。

## 4. 判定してほしいと言われた点への答え

1. **N4→N5→N6 はつながるか**
   - 測量士：つながる。「日本は東京湾平均海面を0にしてそろえる／設計の現場は近くの目印を基準にしてそこからはかる」は、仮の高さの現場でも公共の水準点につないだ現場でも正しい。海と現場を線・寄り・点でつながない決めも正しい。
   - 子ども：今のままではつながらない。つなぎの中身（ひとつの基準からはかる）が声になく、「考え方は同じです」に預けている。画の韻は大きさと線の種類が違って気づきにくく、C6 は「同じです」の 1.9 秒前に鳴る。→ M1・M3。
   - 仮の高さの現場としての正しさ：言葉は正しい。注意は1つで、「（0）」付きの持ち帰る言葉と、0 の丸と同じ置き方・同じ音の □ が重なると「目印＝0」と覚えられる（M1④）。
2. **N10 は正確で言いすぎていないか**：正確で、言いすぎていない（「あわせて」「手がかり」で材料の一つ）。弱いのは「道路」がないことと、B10 の図（2つの層が重なると道の線と坂の線が出る）が言葉より強く「これで設計できる」と見せること。→ M2。
3. **N10 の 1.23 秒のはみ出しはよいか**：**よくない。**カット 55.615 が「手が｜かり」の中に落ち、B10 の決めの絵（坂の線）は 0.63 秒しか映らない。B11 の頭は声「設計の…」と文字「レベル」が同時で、年配の人には読みと聞きがぶつかる。依頼者に却下された所を直した決めの一文なので、自分の画の上で言い終わらせる。M2 の文で 55.33 に収まる。
4. **同じ画・目的のわからない要素・同期のずれ**：同じ素材の秒の重なりはない。同じに見える画は N の寄りの3回（M5）と、コーンとバーの道路わきの構図の多さ（素材の限り）。目的はすべての拍に書いてある。同期のずれは □ の C6・棒（M1③）、N10 のはみ出し（M2）、ラベル「高さの目印」が声より早い（M1③で理由を記録）。
5. **0 の線の絵は、却下された真横のしくみの図に見えるか**：しくみ（機械・目線・水平な線・標尺・水面）は描かないので、同じ物には見えにくい。しかし「0 の線の上に浮いた地面の線と、地面を突き抜ける棒」は断面図の文法で、紺の細い線の図と合わせて技術の図に見える。終わりの絵のように物を 0 の線にじかに立てれば背くらべの絵になる（M4）。

## 5. 別の中心の絵：「そろわない棒が、そろう」

- **芯**：同じ物の高さでも、はかり始める所がばらばらだと、棒の長さがばらばらになる。始める所を一つにすると、そろう。「そろう」を言葉でなく**動き**で見せる（今の計画は「そろう」を言うが、そろわない場合を見せていない）。
- **持ち帰る言葉3つ**：「高さは、ひとつの基準からはかる」「日本は海、道路の設計は近くの目印」「位置とあわせて、道路の設計に使われる」。
- **締めの一文**：「設計が使う、“高さの土台”をはかる。それが、水準測量です。」（今と同じ）
- **看板の動き**：日本の形が消えたあと、山・建物・家の3つの影の下に、高さのちがう短い床の線が3本ばらばらにある（棒の長さもばらばら）。「0」の声で3本の床の線が左から一本の 0 の線にすべり込んで一つになり、棒の長さが本当の高さに変わる（C6）。現場では、道の上の3点の下にばらばらの短い線 → □ から伸びる一本のオレンジの線にそろう（同じ C6）。
- **ナレの見本**：「はかり始める所がばらばらだと、高さはくらべられません。」「日本は、東京湾の海の高さを0にして、そろえています。」
- **今の案と比べて**：「そろえる」の意味が子どもに見える。弱い所は、図の連続が約 1.5 秒のび（B5 の図 7.27→約 8.8 秒、決まりの 12.6 秒の内）、「ばらばら」の画が教科書の比べの図に近づくこと。
