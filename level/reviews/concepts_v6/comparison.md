# 水準測量パート 中心の案の比較（作者を伏せた6案）

批評の目：親（小3の子連れ、専門知識ゼロ）／測量士（20年）／映像の編集者。
読んだもの：X1〜X6、共通メモ a・b、playbook/25、prompts/15、1本目の内容計画（reference/plans/content.md）、ブリーフ、docs/04 §8、foundation_v4 §2・§7。

前提にした「前の案」の骨組み（依頼者が「微妙」と言ったもの）：
**見えない水平面（水の面）→ 線から下への深さ → クイズ「深いほうが低い」→ 水準点 10.000 から引き算 → 階段（尺取り）で運ぶ → 下水・トイレの水で「なぜ」**。
監督の診断：背負いすぎ／考えが8つ／たとえの重ね／人が脇役／1本目との対（位置⇔高さ）を使っていない／図が半分で講義調／現場は道路なのに下水。

## 3. 事実の危うさ（測量士が止める所）

### 3.0 4つの論点についての判定

**(a) 道の縦断測量を、水準測量パートで見せてよいか（路線測量パートとの取り合い）**
- 作業規程の準則では、1〜4級水準測量・簡易水準測量は「基準点の高さ（水準点・仮BM）を決める」作業で、**縦断・横断測量は「路線測量」の中の作業**（共通メモ a・b の [A][R1][R2]）。発注の内訳でも、仮BM設置（3級水準）と縦断・横断は別の項目になっている。
- ただ、使う機械と読み方は同じ（レベルと標尺、器械高から読みを引く）。「水準測量の**やり方**で、道の高さをはかる」は正しい。
- **判定**：見せてよい条件は2つ。①章扉に「路線測量」のアイコンがあるなら、その担当と取り合わない形にする。具体的には、**横顔の線を最後に路線のアイコンへ渡し**（1本目の「点つなぎ」で、基準点から地形・路線のアイコンへ線がのびたのと同じ形）、道の線を引く主語を「道をつくる人」にする。②声で「縦断」と言わない。**部門に聞く前に、この案で原稿を固めない**。それが最大の危険（§4.10）。

**(b) 「数字が大きいほど低い」の扱い**
- 事実としては正しい（読み＝視線から標尺の底までの長さ。foundation §2.2 の4）。
- 前の案はこれを**クイズ**にして山にした。今回は**クイズにしない、題にしない、文字の山にしない**。図で棒の長さとして見えれば足りる。声は一度、2秒（「長いほど、地面は低い」）。主役は「つなぐと道の横顔」に譲る。
- 気をつける所：「数字」と言うと、読みの数字（標尺の目盛り）と標高（高さそのもの）を家族が混ぜる。**標高の数字は画面に出さず、棒の長さだけを見せる**。読みの数字を出すなら「イメージ」と添える。

**(c) 往復の扱い**
- 往復観測は、水準点・仮BMを決める水準測量の決まり（許容差 2.5mm√L など、級で変わる）。**道の縦断測量では往復はふつうではなく**、はじまりと終わりを高さの目印に結んで確かめる（閉合・結合）【要監修】。
- X1 の N10「行きと帰りではかって」は、縦断の絵と組み合わせると**中の事実が食い違う**。X6 の「ほんの数ミリなら合格」は級と距離で変わる値を言い切っている。
- **判定**：縦断の絵を採るなら、往復は言わない。言うなら「最後に、もう一度目印につないで、ずれを確かめます」【要監修】の一文まで。勝つ組み合わせでは、確かめるは**しくみとして説明せず、顔の寄りでの「ミリの違いも見のがさない」という態度**にとどめる。

**(d) 標尺1本の素材で言えること**
- 言える：観測者が1人、遠くで標尺を立てる人が1人、標尺手がものさしを持って機械の横を通り歩く（S 168〜172）、立って野帳に書く（K 15.5〜）。
- 言えない（図だけで見せ、【要監修】を付ける）：2本目の標尺、後ろ・前の盛り替え、S 168 の歩きが「後ろ→前」か「次の点へ」か、往復。
- 逆に、**1本の標尺が点から点へ立ち替わる絵は、縦断測量のやり方（1回据えた機械から何点も読む＝中間視）にそのまま合う**。X1 の「標尺が4本同時に立つ」図より、**1人の標尺手が順に歩いて立つ図のほうが、事実にも素材にも近い**。

## 4. 勝つ組み合わせ（1番）

### 名前：「ふたりで描く、道の横顔」
**芯は X5（真横から見た道、1本目と対の締め）。骨組みと拍の表は X1。看板の動きは X4（遠くの人が手前と同じ大きさになる）。手で書く1カットは X2。** 「運ぶ」系（X3・X4 中盤・X6）の引き算・尺取り・往復は**全部捨てる**。

前の案との違いを一言で：**前の案は「高さのしくみの講義」、この案は「二人が歩いて、道の横顔を描き出す話」**。物理は同じでも、主語が人、出口が道の形、枠が1本目との対。

### 4.1 このパートが運ぶもの（1文）
**「水準測量は、測量部門の中で“高さ”を受け持つ作業。ふたりで一本の水平な線をつくり、そこから地面までをはかって、道の“横顔”を描く。」**
背負わないもの：海からの高さ・国の高さのしくみ・下水と水・往復の許容差・道の設計そのもの。

### 4.2 持ち帰る言葉3つ
1. 「**ふたりで、地面の高さをはかる**」
2. 「**まっすぐな線から、下までをはかる**」（長いほど低い、は図の棒で見えればよい）
3. 「**つなぐと、道の横顔になる**」

### 4.3 締めの一文
**「ふたりで、道の“横顔”をはかる。それが、水準測量です。」**（画面：「道の “横顔” をはかる」）
- 別案 (b)（1本目と続けて上映すると決まった場合）：「真上から見ると、位置。真横から見ると、高さ。それが、水準測量です。」
- 別案 (c)（役割を言いたい場合）：「道をつくる人が使う、“道の横顔”をはかる。それが、水準測量です。」
→ (a)／(b)／(c) を依頼者に並べて選んでもらう。おすすめは (a)。人と形が両方入り、短い。

### 4.4 中心の絵
**紙に横線を1本。その下に、でこぼこの道。線から地面まで棒を何本かおろし、棒の先をつなぐと、道の横顔が出てくる。**
棒をおろすのは、**ものさしを持って歩く人**。標尺手が立つたびに1本ずつ棒が出る。だから「横顔」は、**その人が歩いた跡**として見える。
子どもが家で言うこと：「まっすぐの線から下までをはかって、つなぐと道の横顔になるんだよ。ものさしを持った人が歩いて描くの」

### 4.5 なるほど（1つだけ）
- 見る前：道は平ら。高さは、下から上へものさしを当ててはかるもの。
- 見た後：**高さは、空中に引いた一本の水平な線から“下へ”はかる。だから、つなぐと、平らに見える道の横顔（ゆるい上り下り）が出てくる。**
- 「長いほど低い」はこの途中の一歩として、棒の長さで見せる。クイズにはしない。

### 4.6 看板の動き：「奥行きがたたまれて、真横になる」（1本目の「奥へ倒れて真上」と対）
1本目は、写真が**奥へ倒れて**真上の図になり、**人が消えて点が残った**。2本目は、写真の**奥行きがたたまれて**真横の図になり、**人が残って、二人が同じ大きさで並ぶ**。同じ「写真の空間が図になる」の家族で、軸が反対、残るものが反対（点⇔人と線）。
X1 の rotateY（写真が縦の軸で回る）は使わない。ページめくりの汎用の回転トランジションに見える危険（docs/04 §8）があり、1本目の「倒れる」とも近すぎる。

### 4.7 なぜ大事か（家族の知る物で、背負いすぎない範囲）
**「自転車でのぼる坂の、かたむき」**を1つだけ使う。
- 道の横顔（縦断）から決まるのは、まさに**道の上り下りの坂**。家族が毎日、自転車・ベビーカー・徒歩で体で知っている物で、しかもこのパートの範囲（道の高さ）に収まる。
- 雨・水たまりは使わない（前の案の水の話をくり返さないため。横断勾配の話にもなり、図が増える）。家の前の段差も、横断・すりつけの話になるので使わない。
- 画：横顔の上に、「道をつくる人」が引く**なめらかな紺の線**（新しい道の線）が重なる。自転車の絵は描かない（ストック風のアイコンになる）。言葉だけで坂を思い浮かべさせる。
- ナレ：「道をつくる人は、この横顔に、新しい道の線を引きます。」「自転車でのぼる坂のかたむきも、ここから決まります。」【要監修】
- 主語は「道をつくる人」。測量が設計を背負わない（X2 の言い過ぎを避ける）。路線測量のアイコンがあるなら、ここで横顔の線がそのアイコンへ流れて灯る（1本目の点つなぎと同じ渡し方）。

### 4.8 人をどう主役にするか
1. **最初の実写から二人**：題のあと、K で二人を一画面に。ラベル「レベル」「標尺」は人の体に重ねない。
2. **看板の中でも人が残る**：なぞった二人が同じ大きさで並び、標尺手が歩くことで横顔が描かれる。図の中の主語が人。
3. **しくみの真ん中に実写の歩きをはさむ**（S 168）：図 → 歩く人 → 図。
4. **手で書く1カット**（X2 から）：K 15.5〜20.5 の、立って黄色い野帳に書く手。「読んだ長さは、その場で手帳に。」
5. **顔の寄りに、ナレのない2〜3秒**（N 6.0〜11.0）：「ミリの違いも、見のがさない」は、この顔の上で一度だけ。
6. **締めは二人の引き**：観測者と遠くの標尺手の間に点線（体を通さない高さ）が引かれ、縮んで章扉の水準アイコンに戻る。
7. 撮り足しを1つだけ頼む（5分）：**標尺手の顔と、ものさしを両手で立てる手の寄り**。これで「うちの人が見えなかった」が消える。前提にはしない。

### 4.9 尺：**28小節（約70.8秒）をおすすめ**

- 実写は約40秒しかない。81秒では、のぞく・書くのくり返しでゆるむ（X2 の自己申告どおり）。28小節なら実写が約55%で、図が続くのは最長でも約8秒（9〜10小節と12〜14小節の間に実写をはさむ）。
- 1本目（60.7秒）より約10秒長い分は、「なぜ大事か」の1拍（坂）。シリーズで並べても、1.5倍（91秒）より自然。

### 4.10 残る最大の危険
**路線測量パートとの取り合い**。章扉に「路線測量」があって、そのパートが縦断図を見せる予定なら、この案の芯（道の横顔）を先に取ることになる。1本目で避けた「背負いすぎ」の別の形。
- **手当て**：ゲート1の前に部門へ一問だけ聞く。「水準測量パートで、道の横顔（縦断）を見せてよいか。路線測量パートはあるか」。
  - よい → このまま。
  - 路線パートがある → 横顔は「描いて渡す」まで。B9 で横顔の線を路線のアイコンへ流し、道の線は描かない。締めは (c)「道をつくる人が使う、“道の横顔”をはかる」。
  - 縦断は路線パートが専有、と言われた → 2番手（§5）に切り替える。
- 次に大きい危険：**なぞりの品質**。外形のなぞりが雑だと「切り絵」「AIっぽい」に見える。外形は SVG のパスとして部品に持ち、線の太さと描く速さをそろえる。K の標尺手は小さい（切り出しても約8画素幅）ので、なぞりは実写の上で最初の0.3秒だけ重ね、すぐ図の中で大きくする。
- 3番目：**物理は前の案と同じ**。依頼者が「また水平な線か」と感じる恐れは残る。答えは見せ方の3つの違い：水という言葉を一度も出さない、クイズにしない、線の出どころを「二人のあいだ」にする。ゲートの報告では、前の案との違いを1行で先に示す。

## 5. 2番手の組み合わせ

### 「ふたりの一本線」（X4）＋手帳（X2）＋往復は言わない
- 芯：二人のあいだの真横の線で高さを読み、近くの水準点から**現場の高さの目印（仮BM）まで高さを運ぶ**。看板は同じ「遠くの人が同じ大きさになる」。
- 効く場合：①部門が「縦断は路線パートのもの」と言ったとき、②素材の現場が仮BMの設置だとわかったとき。水準測量（作業規程の水準測量そのもの）の範囲にきれいに収まる。
- **1番に負ける理由**：
  1. 中盤が**前の案と同じ骨組み**：後ろ−前の引き算（1m20→1m50＝30cm）と、尺取りで運ぶ（前の階段の図）。依頼者の「微妙」に正面から答えられない。
  2. 「高さを運ぶ」は子どもの絵にならず、出口（工事の目印）も家族の物にならない。なぜ大事かを「坂」で言うと、仮BMから坂までの距離が遠く、つながりが一段増える。
  3. 1本目との対が「点→線」の言葉だけで、真上⇔真横の形の対ほど強くない。
- 使うなら：引き算の数字を出さず「前のほうが長い＝低い」を棒の長さだけで見せる。運ぶは1回の尺取りだけ（3回以上くり返さない）。締めは「のぞく人と、持つ人。ふたりで、高さを運ぶ。」

## ひとことの結論

**中心は X5 の「道を真横から見る」を、X1 の拍の表で組み、X4 の「遠くの人が同じ大きさになる」看板で人を主役にする**。「高さを運ぶ」系（X3・X4 の中盤・X6）は、前の案の引き算・階段・往復を骨組みごと持っているので、依頼者の「微妙」に答えられない。路線測量パートとの取り合いだけは、原稿の前に部門に聞く。
