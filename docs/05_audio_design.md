# 05 音響設計

元動画の音（BGMのみ・権利不明）は**すべて捨てる**。音は4つの層で新しく組み立てる。上映会場のスピーカーは良くない前提で、**ナレーションが確実に聞き取れること**を最優先にする。

## 1. 層の構成

| 層 | 役割 | 入れどころ |
|---|---|---|
| ナレーション（VO） | 意味を運ぶ主役 | 全体 |
| 環境音（AMB） | 現場の空気（風・草・鳥・遠くの車） | 実写の区間。図解の区間では消すか、ごく薄く |
| 効果音（SE） | 「はかる」「決まる」の瞬間を耳で示す | 照準が合う／測距／点が決まる／橋がつながる、の数か所だけ |
| BGM | 感情の流れと速さ | タイトルから。冒頭6秒は入れない |

## 2. 音の流れ（構成Aの場合）

| 区間 | 音の設計 |
|---|---|
| 0:00〜 冒頭 | 環境音だけで静かに始める（風と鳥）。ナレーションN1 |
| タイトル | 照準が合う瞬間に短い電子音「ピッ」→ その拍からBGMが入る |
| しくみ（D1〜D3） | BGMは控えめに一定のテンポで進む。測距の電子音、点が決まるクリック音は小さく |
| 答えの前（N7a「――」） | **BGMを0.5〜1秒抜いて無音に近い「間」**を作る |
| 答え（N7b）〜日常 | BGMが少し開いて広がる |
| 締め | BGMはフレーズの終わりで自然に終わる（途中でフェードアウトしない）。必要なら小節単位で曲を編集する |

## 3. レベルとミックスの目安

- 基準：ナレーション。BGMは**ナレーションが鳴っている間はナレより約15〜18dB下**、ナレがない所では約6〜8dB下まで上げてよい。
- 環境音はナレより約20dB下。効果音はナレより大きくしない。
- BGMの下げ上げは、自動のサイドチェイン（ポンピングが出やすい）より、**手で書いた音量の変化（キーフレーム）**を優先する。下げはナレ開始の0.3〜0.5秒前から。
- すべての音の切れ目に10ms以上の短いフェードを入れる（プチッというノイズ防止）。
- 完成時：**統合ラウドネス −24 LUFS（±1）、True Peak −2 dBTP以下**（日本の放送基準 ARIB TR-B32 の目標値に準拠。全パートで同じ値に合わせることが一番大事）。48kHz・ステレオ。
- ナレーションの帯域（おおむね1〜4kHz）を、BGMのメロディや効果音でふさがない。

## 4. ナレーション

### 仮ナレ（編集のタイミング決め用）
- **VOICEVOX**（無料・商用利用可。キャラクターごとの規約に従い、多くは「VOICEVOX:キャラクター名」のクレジットが必要）。落ち着いた声のキャラクターを選ぶ。
- または **AivisSpeech**（ソフトは無料。音声モデルごとにライセンスが異なるので、使うモデルの条件を確認する）。
- どちらもローカルで動かす。使ったキャラクター・モデル・規約URLを台帳に記録する。

### 本ナレ（完成版）＝社員の肉声を推奨
- 理由：機械の声より人の声のほうが理解と好感につながる（学習研究の「音声の原則」）。「私たちの仕事です」は本人の声で言ってこそ成立する。家族参観という場にも合う。
- 候補：測量部門の若手社員など、落ち着いて読める人。
- 収録のしかた（スマホで可）：
  - 静かで、カーテンや布の多い部屋（響かない部屋）。エアコン・換気扇は止める。
  - スマホを口元から20〜30cm、少し斜めに置く（息が直接当たらないように）。
  - 1文ずつ区切って、各文3テイク。ゆっくり、文末まで気を抜かない。
  - 読みの注意：基準点（きじゅんてん）、測量（そくりょう）。
- 処理（Claude Code が FFmpeg で行う）：低域カット（80Hz）→ 軽いノイズ低減 → 歯擦音の抑制 → 軽いコンプレッション → 必要なら3kHz付近をわずかに持ち上げ → 音量を整える。強いノイズ除去はかけない（声がこもる）。
- 本ナレの尺は仮ナレと変わるので、**タイミングは1つのデータファイルにまとめておき、差し替え時に数値だけ直せば全体が追従する作り**にしておく（docs/06）。

## 5. BGMの選び方

- 曲調：誠実・前向き・あたたかい。ピアノ、アコースティックギター、やわらかい弦、軽い打楽器。テンポ85〜105BPM。
- 避ける：歌入り、EDM、映画予告風の大太鼓、口笛やウクレレの「よくある企業VP」っぽさ、メロディが忙しく声とぶつかる曲。
- 構成：静かな入り → 徐々に積み上がる → 開く → **きれいな終わり**がある曲。90秒以上、または小節単位で編集しやすい曲。
- 選定の流れ：Claude Code が条件と検索キーワードを示し、**人間が試聴して2〜3曲から選ぶ**（好みと会場の雰囲気は人間が判断する）。選んだ曲は `hyperframes beats` で拍と小節を検出し、カット点や図解の動きを寄せる。
- 入手先の例（無料・商用利用可。**規約は利用時点で必ず読み、URL・規約・ダウンロード日を台帳に記録**）：
  - DOVA-SYNDROME（日本のフリーBGMサイト。曲ごとの個別条件にも注意）
  - Pixabay Music（Pixabay Content License）

## 6. 効果音・環境音

- 効果音の例：照準が合う電子音、測距の短い電子音、点が決まる小さなクリック、橋がつながる低めの「カチッ」。**合わせて4〜5種類まで**。
- 単純な電子音は FFmpeg で合成できる（権利の心配がない）。
- 素材を使う場合の入手先の例：効果音ラボ（商用利用可・クレジット不要。規約は要確認）、Freesound（**CC0のものだけ**を使う）。
- 環境音は映像の季節・場所に合わせる（夏の草原：風、草の揺れ、鳥）。映像にないもの（セミの大合唱、波音など）は入れない。

## 7. 使わないもの

- 元動画のBGM（権利不明）
- AIによる音楽生成（例：MusicGen は公開されている重みが非商用ライセンス）
- 公式の提供元ではない経路で使う合成音声サービス（利用規約上あいまいなもの）
- 規約が確認できない「フリー素材」
