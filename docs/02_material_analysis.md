# 02 素材分析（事前調査メモ）

キット作成時に行った分析。**Claude Code は Phase 1 でこれを自分で検証し直し、違っていれば修正すること**（時刻は±数フレームの誤差あり）。

| 項目 | 値 |
|---|---|
| 映像 | H.264、1920×1080、29.97fps（30000/1001）、約4.6Mbps |
| 音声 | AAC、44.1kHz、ステレオ、128kbps |
| 長さ | 39.8秒 |
| 性質 | YouTube配信用に再圧縮された**完成動画**。編集用の元素材ではない |

## 2. 画質の所見

- 圧縮ノイズ・ブロック感があり、輪郭の強調（シャープネス）が強め。**さらにシャープをかけると悪化する**。
- 緑の彩度が高く、晴天カットと曇天カットで色味がばらつく。
- 空が白飛び気味のカットあり（S04、S10）。
- 拡大は**1.2倍程度までが無難**。1.4倍で甘さが目立ち始める（大画面上映で要確認）。

## 3. 焼き込みテロップ（最大の課題）

旧来型の青い光沢カプセル型テロップ「基準点測量／TS(トータルステーション)」が全編に焼き込まれている。

| 区間 | 位置（1920×1080座標、概略） | 備考 |
|---|---|---|
| 0.00〜8.91秒（S01・S02） | 下中央の大きなカプセル：x 456〜1540、y 780〜1020（**Phase 1 実測：上端 y779、その上に影。y<765 だけ使う**） | 0〜0.8秒は細い帯が左右に伸びて出現するアニメーション |
| 8.91秒〜最後（S03〜S10） | 左上の小さなカプセル：x 20〜645、y 30〜172（**影を含め y≈176。y≥180 だけ使う**） | カット切替と同時に移動。以後固定 |

対応方針（優先順）：
1. **テロップ・BGMなしの元素材（クリーン素材）を入手する**。これが最良。
2. 入手できない場合、カットごとに次を比較して決める（Phase 3 で比較表を作り、人間が選ぶ）。
   - **切り出し（クロップ＋拡大）**：S03以降は上端175pxを外せば消える（約1.19倍）。S01・S02は下側を外す必要があり約1.39倍（**実測後 1.41倍**）。
   - **覆う（デザイン要素で隠す）**：章タグやラベル板を、焼き込みの位置に意図的なデザインとして置く。出たり消えたりすると不自然なので、使うなら一貫したルールで。
   - 1本の中で方法を混ぜてよいが、**観客に「何かを隠している」と感じさせないこと**が条件。
- AIの消去・修復（インペイント）は、動くカメラで大面積だと破綻しやすく、主要な研究系ツールは非商用ライセンスが多い。**使わない**。

## 4. 音声

- 中身は**BGMのみ**（ナレーション・現場音なし）。約14kHz以上が削れた非可逆圧縮音源。終盤で自然にフェードアウト。
- 権利関係が不明なので**完全に破棄**し、ナレーション・環境音・効果音・BGMを新たに設計する。

## 6. 足りない画（ギャップ）

| 足りないもの | なぜ必要か | 代替案 |
|---|---|---|
| **基準点の標識（金属標・標石）のアップ** | 物語の主役「最初の一点」が実物で一度も映らない | 会社や会場の近くにある標識をスマホで撮影（横向き・固定・10秒）。無ければ図解で描く |
| 完成した道路・橋・日常の風景 | 「生活とのつながり」を実感させる | 自社実績の写真（掲載許可済み）。無ければ図解の線画で表現 |
| TSの画面・数値の寄り | 「精密にはかっている」実感 | 図解の数値表示で代替 |
| 現場の音 | 現場の空気感 | 環境音素材で作る（docs/05） |

## 7. 権利の確認事項

- 映っている人物の上映への同意（社内上映でも確認しておくと安心）。
