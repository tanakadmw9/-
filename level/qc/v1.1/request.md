# 作り手からの依頼（v1.1）

このパートは「水準測量（レベル）」。基準点測量パート（v4.10）と同じシリーズの2本目で、同じ型（章扉→題→現場→用語→しくみ→人→役割→締め、24小節、同じ曲）で作った最初の書き出し。観客は家族参観の家族（子ども・年配者を含む）。

## 前の版からの変更（何を、なぜ）
- 初版。計画は plan v1 → 別の目の批評（11/20）→ v2 で直してから作った。中心の絵は「見えない水平の線」：のぞく目線＝オレンジの**点線**（前のパートの「光の線」＝実線と区別）。決めは「目盛りが大きいほうが、低いんです。」

## 特に見てほしい所（3つまで、タイムコードつき）
1. 25.9–31 秒：看板の動き。人が離れたレベルの静止に目線の点線が伸び（27.7）、写真が縮んで横から見た図の機械になる（29.4–30.5）。つながって見えるか、点線が「光」や「レーザー」に見えないか。
2. 29.5–37.9 秒：しくみの図。子どもが「どっちが低い？」に答えられるか。出る順（地面→水準点→標尺→同じ距離の矢印→0→読み 1.2/1.8 m→文字→差の段 0.6 m）が多すぎないか、読める時間か。
3. 43–50.5 秒：高さのバトンの図。機械が前へ、後ろの標尺が追い越す動きがわかるか。N7（7.7 秒）が画と合っているか。
