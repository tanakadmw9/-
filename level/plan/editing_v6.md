## 3. 看板 fold_side（32小節の秒）

### 3.1 作り方
- **部品**：`comp/compositions/fold_side.html`（新）。1920×1080 の SVG に、下から順に次を重ねる。
  1. 止めた写真 `<image>`：K 8.5 を 1.32 倍の窓で。ぼかしは `02_intermediates.py` で焼き込む。
  2. 紙 `<rect>`。
  3. なぞりの `<g>` が5つ。
  4. 点線。
  5. 棒と点。
  6. ラベル。
- **なぞり**：外形の SVG パスを手で描き、部品に直接持つ。輪郭線だけで、顔・目鼻・ヘルメットの印刷は描かない。
  - 地面（縁石）と、三脚の脚 3本は `<line>`。
  - 観測者・標尺手・標尺・機械は `<path>`／`<rect>`。
  - 太さは 4 px でそろえる。`pathLength="100"` の `stroke-dashoffset` を 100→0 にし、1本 0.5〜0.6 秒で描く（d0_sea.html と同じやり方）。
- **たたむ**：
  - 線は端点を `attr:{x1,y1,x2,y2}` で動かす。
  - 人と機械は `<g>` を GSAP の `x`・`y`・`scale`（`svgOrigin` は足もと）で動かす。2D の移動と拡大だけで、rotateY・3D は使わない。
- **MorphSVG**：`node_modules/gsap/dist/MorphSVGPlugin.min.js`（3.15.0、無償の標準ライセンス）にあるが、`comp/assets/vendor/` には入っていない。この作り方なら要らない。
- **色**（docs/04）：
  - なぞりの線は、写真の上では白（外側に紺 30% の縁）。紙に溶けるあいだに紺へ変える。
  - 点線（6 px、18／12 の破線）と、いま読んだ棒（12 px）はオレンジ。読み終わった棒・点・横顔・新しい道の線は紺。
- **動き**：
