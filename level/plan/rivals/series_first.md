## 0. 出発点（2案に共通）

### 0.1 1本目から引き継ぐもの・変えるもの

| | 1本目「基準点測量」A案 | 2本目「水準測量」で対にするもの |
|---|---|---|
| はかるもの | 位置（どこ） | 高さ（どのくらい上か下か） |
| 看板の向き | 実写が**奥へ倒れて真上**の図になる | 実写が**横に開いて真横**の図になる（案1）／真横の図の中で**ものさしが進む**（案2） |
| モチーフ | **点**（照準＝十字＋円。点に合う） | **線**（レベルがつくる水平な一本の線） |
| 目印の記号 | 紺の △（地図の三角点の形） | 紺の □に点（地図の水準点の形）【要監修：地図記号の形】 |
| 締めの形 | 「ほかの測量が使う “はじまりの点”」 | 「○○が使う “○○”」の同じ組み方で、中身を変える |
| 章扉 | 基準点のアイコンが灯り、照準になる | 水準のアイコン（標尺）が灯り、その目盛りの一本が**横にのびて線になる** |
| 終わり | 照準が縮んで章扉のアイコンに戻る | 線が縮んで章扉のアイコンに戻る |

「1本目は点、2本目は線」。続けて見たとき、形は同じ家族なのに、看板の向き（真上／真横）とモチーフ（点／線）が入れ替わるので別物に見える。

### 0.2 専門の調べで足したこと（foundation_v4 §2 に加えて）
- 道路の仕事では、水準測量のやり方で**道の中心の線にそって何十mおきかに地面の高さをはかり（縦断測量）**、道を真横から見た図（縦断面図）をつくる。横の向きも同じように高さをはかる（横断測量）。中心の点の間隔は目的で変わり、20m がよく使われる [A]。
- 1回据えた機械から、**何本でもものさしを読める**（水平な線の高さが一度わかれば、あとは「線から地面までの長さ」を引くだけ。器械高を使う読み方）。縦断測量はこのやり方で多くの点をはかる【要監修：素材の現場がこの作業か】。
- 道の表面は平らに見えても、雨水を端の側溝へ流すために横に少し傾けてある（車道で 1.5〜2% が標準）[B]。高さがミリでそろっていないと、水たまり・段差になる。→ 「なぜ大事か」の裏づけ。ナレでは言い切らない。
- 公共測量の作業規程では、縦断・横断測量は「路線測量」の中の作業として並ぶ [A]。**章扉に「路線測量」のアイコンがあるなら、役割の取り合いに注意**（案1の弱点1）。

[A] 札幌市 公共測量作業要領（路線測量） https://www.city.sapporo.jp/doboku/sokuryo/gijutu/documents/7rosenn.pdf
[B] 浜松市 道路のユニバーサルデザイン指針（横断勾配は道路構造令に準拠、1.5%／2.0%） https://www.city.hamamatsu.shizuoka.jp/dourokikaku/traffic/douro_ud/09.html
ほかは foundation_v4 §7 の [1]〜[12]。

## 案1「道の横顔」（推奨）

### 1. 名前と一文
- **名前**：道の横顔
- **このパートが運ぶもの**：「水準測量は、測量部門の中で**“高さ”を受け持つ作業**。水平な一本の線から地面までをはかって、道をつくる人が使う“道の横顔”を描く」。
- 背負わないもの：まちづくり全体、日本中の高さのしくみ（海からの高さ・原点・衛星の話）。

### 2. 持ち帰る言葉と締め
1. 「地面の**高さ**をはかる仕事」
2. 「**まっすぐな線から下まで**をはかる。長いほど低い」
3. 「つなぐと“**道の横顔**”。それで道の高さが決まる」

締めの一文：**「道をつくる人が使う、“道の横顔”をはかる。それが、水準測量です。」**
締めの別案：(b)「道の高さは、この一本の線から。」 (c)「高さの目印から、道の横顔へ。」

### 3. 中心の絵
- **絵**：紙に横線を1本まっすぐ引く。その下に、でこぼこの地面。線から地面まで、たてに何本も棒をおろす。棒の先をつなぐと、地面の形＝**道の横顔**が出てくる。
- **子どもが家で言うこと**：「まっすぐの線から、下までの長さをはかるんだよ。長いところは低いの。つなぐと道の横顔になる」。紙と鉛筆で再現できる。
- **見る前**：高さは「下から上へ」ものさしを当ててはかるもの。道は平らなもの。
- **見た後の「なるほど」**：高さは、空中に水平な線を1本つくって「**上から下へ**」はかる。だから**長いほど低い**（ものさしの常識と逆）。そして、平らに見える道にも横顔（ゆるい上り下り）がある。
- 削ったもの：海からの高さ、2本の目盛りの引き算、行き帰りの往復の図、水・雨・下水のたとえ。**「線から下まで」1つに賭ける**。

### 4. 看板の動き：「写真の奥行きが、横に開く」（秒は完成尺の目安）

### 6. シリーズの中の位置
- 1本目「位置の目印をつくる」→ 2本目「高さをはかる」。**目印は2つ：位置は基準点（△）、高さは水準点（□）**。記号の形で対にする。
- 1本目は真上（地図の見方）、2本目は真横（横顔の見方）。家族は2本を見て「上から見ると位置、横から見ると高さ」と、2つの見方を持ち帰る。
- 締めの組み方「○○が使う “○○”」と、章扉→アイコンに戻る閉じ方は共通。中身（点→線、ほかの測量→道をつくる人）は変える。

### 7. 実写と図の割合、角度の工夫
- 実写 約43.6秒（62%）、図 約27.2秒。図の連続は最長 B5 の約12秒（はじめの約1秒は写真が回りながら見えている）。
- 角度の並び：章扉（図）→ 機械の寄り（N）→ 引きの早回し（S1か所目）→ 顔の寄り（N）→ 引きの切り出し（K）→ 図 → 引き（S2か所目）→ 図 → 顔の寄り（N）→ 引きの切り出し（K）→ 引きの早回し（S1か所目）→ 全体の引き（K）→ 終わりの画。**寄りと引きを交互に**し、同じ素材が続かない。
- 同じ秒は二度使わない（K は 3.5–6.66 と 9.0–11.53 を切り出し、15.5–23.1 を全体で。N は 0.3–1.0、1.5–4.03、6.0–11.0）。
- 視線が逆になる所（N→K）は2か所。どちらも「顔の寄り→引き」で大きさが大きく変わる所に置く。
- カメラの動きは3か所だけ：タイトルの寄り、締めの寄り、看板の「横に開く」。

### 8. この案の弱点（本気で）
1. **役割の取り合い**：道の横顔（縦断）を描くのは、作業規程では「路線測量」の中の作業。章扉に路線測量があれば、そのパートの中身を先に取ることになる（1本目で避けたこと）。→ 部門に「水準測量パートで縦断を見せてよいか」を聞く。だめなら締めを「道の高さを決める、もとの高さをはかる」に下げ、道の線（B7 後半）を削る。
2. **前の案と近い匂い**：「真横へ回す」「長いほど（深いほど）低い」は、v5 の見え方と重なる所がある。違いは、たとえ（水・プール・トイレ）を全部捨てて、**結果の形（横顔）を見せる**こと。それでも依頼者が「また横に回るのか」と感じる恐れはある。
3. **看板の素材が細い**：K の遠くの標尺は幅 5px（1.6倍で約 8px）。線画でなぞる「形のつなぎ」が、細い棒1本に頼っている。大画面で「同じ場所を横から見た」と感じられず、ただ「絵に変わった」に見える恐れ。
4. **素材の現場が縦断測量かは不明**：素材は1本の標尺を読み続けているだけで、何点も読む様子は映っていない。図の「標尺が何本も」は一般のやり方の説明になる【要監修】。
5. **「長いほど低い」は約2秒**：このパートの一番の「なるほど」が速すぎて、子どもが取りこぼすかもしれない。文字と鉄琴の音程で補うが、試写3で確かめる必要がある。
6. **「なぜ大事か」が抽象的に残る**：「道の高さとかたむき」までで止めた（雨水・水たまり・段差を削った）。家族の生活の実感（「水たまりができない道」）は弱い。
7. **480p の S を全画面で3回**（早回し2回と B6 の 7.6秒）。B6 は長く、大画面で甘さが目立つ。
8. **ナレなしの間が約6.8秒**（B9、54.3〜61.1）。意図した間だが、子どもが離れる長さかもしれない。
9. **曲が1本目と同じ**：続けて上映すると、同じ曲が2回流れる。部門全体で決める話（1本目の編集計画 §11 と同じ課題）。

## 案2「高さのバトン」（本気の別案）

### 1. 名前と一文
- **名前**：高さのバトン
- **このパートが運ぶもの**：「水準測量は、測量部門の中で、**高さの目印から現場まで、高さを運んでくる作業**」。
- 背負わないもの：日本中の高さのしくみ（2025年からは衛星と組み合わせて国の高さを決めている。だから「日本中の高さをリレーで運ぶ」とは言わず、**近くの目印から現場まで**に絞る）。

### 2. 持ち帰る言葉と締め
1. 「高さの目印から、高さを**運ぶ**」
2. 「2本のものさしの**差**で、となりの高さがわかる」
3. 「**行きと帰り**で、ずれを確かめる」

締めの一文：**「道の工事が使う高さを、目印から運んでくる。それが、水準測量です。」**
締めの別案：(b)「位置は基準点。高さは、水準点から。」 (c)「高さは、となりへ、となりへ。」

### 3. 中心の絵
- **絵**：まんなかに機械、前と後ろにものさし。後ろのものさしが機械を追いこして前へ。機械も前へ。尺取り虫のように進むたびに、オレンジの「高さの札」がものさしからものさしへ渡っていく（バトン）。
- **子どもが家で再現すること**：両手を尺取り虫のように交互に前へ出して「高さをリレーで運ぶんだよ。帰りもやって、同じならOK」。
- **見る前**：高さは、その場所で地面からはかればわかる。
- **見た後の「なるほど」**：高さは、その場所だけでは決まらない。**わかっている所から運んでくる**もの。だから、行きと帰りの2回はかって、同じになるかで確かめる。

### 8. この案の弱点（本気で）
1. **「差」は子どもに難しい**：2つの目盛りの引き算は、未就学〜低学年には届きにくい。バトンの動きは伝わっても、「なぜ差で高さがわかるか」は大人向けに残る。
2. **91秒は1本目の1.5倍**：シリーズで並べたとき、この作業だけ長い。中身（往復）が長さを要求しているが、部門全体の尺で削られる恐れ。
3. **素材を使い切る**：使える実写をほぼ全部使うので、作り直しの余地がない。S（480p）を4回使う。
4. **しくみの肝はすべて図**：素材には標尺が1本しか映らず、盛り替え（追いこし）も本当にその場面かわからない。図の連続（B5・B6・B7 の後半）が多く、「図解の列」に見える危険が案1より大きい。
5. **声の専門用語が数え方で3つ**：「基準点」を言わないと、シリーズの回収（N12）が弱くなる。
6. **往復は作業の種類で違う**：仮の目印をつくる水準測量では行きと帰りをはかるが、道の縦断測量は片道で目印に結んで確かめることが多い【要監修】。素材の現場の作業と合わない恐れ。
7. **帰りの8小節が「同じことの2回目」に見える**：音楽のくり返しと中身のくり返しが重なって、退屈に転ぶかもしれない。
8. **「高さを運ぶ」は、何か物を運ぶと誤解される**かもしれない（札を物に見せない描き方が要る）。

## 推す案と理由

**案1「道の横顔」を推す。**
- 中心の絵が「線から下まで → つなぐと横顔」の1つだけで、引き算も往復も要らない。子どもが紙と鉛筆で再現できる。
- 1本目と**向き（真上／真横）とモチーフ（点／線）が入れ替わる**ので、同じ家族でありながら別物に見える。看板の部品（写真が回って紙になる）も1本目の作り方をそのまま使える。
- 素材の現場（道路）と結論（道の横顔）がつながり、「多分道路」という現場の事実に合う。
- 尺は 28小節（約70.8秒）。中身に対して91秒は長く、削って1つに賭ける角度に合う。
- ただし弱点1（路線測量との取り合い）は、ゲート1の前に部門と測量士に必ず聞く。だめなら案2の「バトン」の形を、案1の B6（つないで進む）に小さく移す手がある。
