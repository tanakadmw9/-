# 30 事例：基準点測量パート（v4.1 → v4.10、A案と B案）

すべての決定と理由は docs/decisions.md、各版の自動QCと独立レビューは qc/v4.x/（report.md・review.md）、計画書とチームレビューは reference/plans/、B案は reference/teamB/。映像とシート画像は別の zip（media）の reference/。

## 1. 条件

- 建設コンサルタント会社の家族参観ミニシアター。観客は専門知識ゼロの家族（子ども・年配者を含む）。大画面と会場スピーカー。
- 実写は約40秒の完成動画1本だけ（テロップと BGM が焼き込み済み、カット S01〜S10）。新しい撮影なし。スローや水増しはしない。
- 依頼者はスマホで確認する。好みははっきり言うが、理由は短い。

## 3. 声を詰めた過程（好みを比べて決める例）

| 試聴 | 中身 | 依頼者の反応 |
|---|---|---|
| キャラクターの聞き比べ | 3つの声、既定値のまま | 「冥鳴ひまりで。今のは調整してないから？aiっぽすぎるね。」 |
| A・B | 全体の数値（速さ・抑揚・間）の調整 | 「もう少し人間。プロのナレーターみたいに…テンション？声のトーンがあってないし、内容によって読み方を調整してほしいよね」 |
| C | 文ごとの演出（ねらい・強調・文末）を入れる | 「落ち着いた感じすぎて内向的に感じちゃう。もっと自然に調整できないか？」 |
| D・E | 明るく、速く | 「速さを戻して。あとは機械感、イントネーションが変な部分を修正」 |
| F | 速さを標準に戻し、機械感（文末・読点の間）とイントネーション（vv_kana の手直し）を直す | 「一旦これで。」 |

学び：**声の高さ・速さ・抑揚の数値だけでは足りない。文ごとに「何のために言う文か」を書き、それに合わせて読み方を変える。**比較用ファイル（voice samples）を毎回作り、言葉で返してもらう。

## 4. A案と B案

| | A案「はじまりの点」 | B案「地面に“住所”をつける」 |
|---|---|---|
| 入り | シリーズ共通の章扉（作業アイコンの列、基準点だけ灯る）→ 照準がプリズムに合ってタイトル | 実写のコールドオープン（環境音だけ）と問い「この人たちは、何をしに来たのでしょう」 |
| 画 | 16:9 の全画面。焼き込みは切り出し（1.41倍・1.2倍） | 2.39:1 の黒帯で焼き込みを隠す（拡大は約1.06倍・等倍） |
| しくみの見せ方 | 紙の図解に切り替える。D1 実写の静止→倒れて真上の図 D2 | 実写の上に直接描く（AR 風）＋分割画面（左に人、右に観測パネル） |
| 語り | 明るい・標準の速さ、尺の約7割 | 低め・ゆっくりのドキュメンタリー調、尺の約5割、問い→答え |
| 曲 | New Departure（ピアノ、前向き、強い頭がある）を小節で編集 | 緑色の木漏れ日（アコースティック、約86BPM、96kbps）、曲を止める「間」 |
| 締め | 「ほかの測量が使う“はじまりの点”」→ 照準が章扉のアイコンに戻る（円を閉じる） | 帰り道でできること「道ばたの丸い金属のしるしを探して」 |
| QC | 全項目合格 | 全項目合格 |

**依頼者の評価：「圧倒的にA案のほうがいいな」**（理由は言っていない）。

### なぜ A案が選ばれたか（推測。依頼者に確かめていない）
1. **シリーズの型がある。** 依頼者の最初の構成への指摘（「測量部門は複数の作業の紹介があり、その中の1作業」）に、章扉と点つなぎがそのまま答えている。B案はこのパート単体で閉じている。
2. **リズム。** New Departure の強い頭に画の山が乗る。B案の曲は音質が低く、止める「間」が長く感じやすい。
3. **声の調子が依頼者の好みに合う。** 依頼者は「落ち着きすぎて内向的」を嫌った。B案は意図して低く・ゆっくりにした。
4. **しくみが大きく、はっきり見える。** D1→D2 の倒れる動きで「同じ場所を上から見ている」がわかる。B案は分割画面で図が小さくなり、帯で画面全体も小さくなる。
5. **B案の弱さ。** 問いで始める入りは家族参観の冒頭として遠回り、同じカットを2回使った、金属標を線画だけで見せた、「住所」のたとえは誤解の余地がある（監修で注意が要る）。

### A案が B案から取り入れたもの・取り入れなかったもの
- 取り入れた：実写の上の小さな印は「点が決まる」照準だけに絞る、杭の画を目印に使う案は監修待ちとして記録（E1案a）。
- 取り入れなかった：2.39:1 の帯、明朝体、分割画面、音を止めて「ピッ」を聞かせる（A案の 9小節頭は曲の一番強い所で、止める場所ではない）。

## 5. チームレビューと監督の統合（v4.6 → v4.7）

- 9つの視点（10_process.md §3）から約60件の案。監督が原則で「採用・見送り・依頼者に選んでもらう」に分けた。
- **採用の例**：N1 を2つに分けて「ひとつ、」をアイコンが灯った0.55秒後、「基準点測量」を照準の「ピッ」の0.12秒後に／「その目印を」を D0 の頭に遅らせ、言葉「基準点」でしるしが灯る／D1 の札を「はかる機械／トータルステーション」「プリズム」にして「鏡」をやめる／効果音を声の帯域の外の音に／ナレの測り方の誤りを直して BGM が3dB低かった問題を解消／色：S01 を明るく、S02・S04 を暖かく、S06・S08 を冷たく（カットをつないだ時の色の跳びを減らす）。
- **見送りの例と理由**：S03 の木杭を「目印」に使う（仮杭なら誤り。測量士の確認待ち）、S01 に「目印」の札（地面の点が画の外）、D1 の背景を流れる実写に（効果に対して手間が大きい）、尺を延ばす（24小節の格子と曲の構成がこの版の強さ）。
- **依頼者に選んでもらうこと**（v4.10 時点で未決）：N6 の言い方、効果音（効果音ラボか自作か）、環境音と最後の1.5秒、読点の間、ヘルメットの社名（70_beyond.md）。
