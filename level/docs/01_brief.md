# ブリーフ — 水準測量（レベル）パート

- 上映：建設コンサルタント会社の家族参観ミニシアター。測量部門のシリーズの2本目（1本目＝基準点測量）。大画面＋会場スピーカー。
- 観客：社員の家族（専門知識ゼロ、子ども・年配者を含む）。
- 長さ：約61秒（24小節、基準点パートと同じ曲・同じ型）。
- 運ぶもの（一文）：レベルという機械がつくる「見えない水平の線」で2本のものさしを読み、高さの目印から高さをつないでいく仕事。
- 持ち帰る言葉：「高さをはかる仕事」「見えない水平の線で、ものさしを読む」「高さの目印から、高さをつないでいく」。
- 前のパートとの対：基準点＝位置の目印、水準点＝高さの目印。
- 背負わないもの：会社全体の意味、工事の話。
- 声で言う専門用語は2つまで（水準測量・水準点）。レベル・標尺は画面のラベル。
- 素材：社内の実写3本（約3分＋25秒＋13秒）。外部に送らない・公開しない。
