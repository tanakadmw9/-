# 07 品質管理・試写・検収基準

Claude Code は動画を「見る」「聞く」ことができない。だから **(1) 数値で測れることは自動チェック、(2) 見た目は静止画で確認、(3) リズム・音・感情は人間の試写**、と役割を分ける。

## 1. 自動チェック（書き出しのたびに実行し、`qc/<版>/report.md` に残す）

| 項目 | 方法 | 合格条件 |
|---|---|---|
| 仕様 | ffprobe | 1920×1080、30000/1001、H.264・yuv420p、AAC 48kHz ステレオ、尺が計画±0.1秒 |
| 黒コマ・空白 | `blackdetect` | 意図したもの以外なし。映像と音の長さが一致 |
| 意図しない静止 | `freezedetect` | timeline.json に書いた意図的な静止以外なし |
| 焼き込みテロップの漏れ | スクリプト：4fpsで抜き出し、元テロップの位置（切り出し後の座標に変換）に特有の青い光沢色が残っていないか判定。しきい値は元素材で調整 | 全フレームで検出ゼロ |
| 点滅 | 隣接フレームの明るさの変化を集計 | 大きな明滅が1秒に3回以下 |
| テロップ | 文字数と表示時間（docs/04 §3の式）、タイトルセーフ内か、`npx hyperframes check comp`（はみ出し・WCAG AAコントラスト） | すべて合格 |
| ラウドネス | `ffmpeg -af ebur128=peak=true` | 統合 −24 LUFS ±1、True Peak −2 dBTP以下 |
| ナレとBGMの差 | ステムごとに短時間ラウドネスを測り、ナレ区間で比較 | BGMがナレより15dB以上小さい |
| ノイズ | 音の切れ目のフェード有無をタイムラインで確認、波形の不連続を検出 | プチノイズなし |
| 言葉と絵の同期 | キーワード（「角度」「距離」など）の発話時刻を求め、対応する図解の動きの時刻と比較。仮ナレは VOICEVOX の音声合成クエリのモーラ長から、本ナレはローカルの文字起こし（`hyperframes transcribe` など）か手打ちのマーカーから求める | ずれ±0.3秒以内 |
| 事実確認 | 原稿・画面上の【要監修】の数 | 最終版でゼロ |
| 権利 | 使った全素材が credits_and_licenses.md に載っているか | 漏れゼロ |

## 2. 目視確認用の出力

- `npx hyperframes snapshot comp --review`：各場面の頭＋0.3秒と中間のコマ
- 0.5秒おきのコンタクトシート（全体）
- テロップ・ラベルごとの「出た直後／中間／消える直前」の3コマ
- 絵コンテの画と、実際の書き出しの画を並べた比較シート
- Claude Code はこれらを自分で見て、docs/04 の規定と絵コンテの「目的」欄に照らして直してから人間に出す。

## 3. 独立レビュー（サブエージェント）

- 書き出しごとに `video-reviewer` サブエージェントに審査させる（`.claude/agents/video-reviewer.md`）。作った本人ではない視点で、コードを見ずに、ブリーフと画とレポートだけで判断させる。
- 返ってきた指摘は「対応する／しない（理由）」を decisions.md に書いてから直す。

## 4. 人間の試写

| 回 | 誰が | 見るもの | 主な観点 |
|---|---|---|---|
| 試写1（アニマティック） | 制作者（あなた） | 仮ナレ・仮図解の通し | 構成、順番、尺、リズム、わかりやすさの骨格 |
| 試写2（ほぼ完成） | 制作者＋**技術監修（測量士）** | 本番に近い版 | 事実の正確さ、用語、図解の正しさ、画と音の仕上がり |
| 試写3（対象者テスト） | **入社3年目までの社員3〜5名**（測量部門以外を含める） | 本ナレ前でも可 | 家族の目線で伝わるか（下のアンケート） |
| 最終 | 制作者 | マスター | 会場（または同等の大画面とスピーカー）で通しで確認 |

見方のルール：
- 1回目は止めずに通しで見る（観客と同じ体験をする）。2回目に止めながらメモ。
- 大画面＋スピーカーで、会場に近い音量で。ノートPCのスピーカーでもナレが聞き取れるか確認。
- 指摘は「タイムコード＋何を感じたか」で書く（例：「0:34 角度の説明で置いていかれた」）。直し方は書かなくてよい。

### 対象者テストのアンケート（見終わった直後に記入）

1. 基準点測量とは、どんな仕事ですか？（自由記述）
2. トータルステーションは、何をはかる機械ですか？（自由記述）
3. この仕事は、私たちの生活のどこにつながっていますか？（自由記述）
4. わかりにくかった所、速すぎた所はありましたか？（だいたいの時間と内容）
5. いちばん印象に残った場面は？
6. 5段階評価：わかりやすさ／映像の見やすさ／音の聞きやすさ／家族に見せたいか

**合格の目安：問1〜3の要点（「位置の目印をつくる」「角度と距離」「道路や橋がつながる」）を、回答者の8割以上が自分の言葉で書けること。** 届かなければ、どこで理解が落ちたかを問4から特定して直す。

## 5. 検収基準（制作会社の納品物として受け入れられるか）

- [ ] ブリーフの「持ち帰ってほしい言葉」が対象者テストで確認できた
- [ ] 構成に意図があり、絵コンテのすべての要素に目的が書かれている
- [ ] 実写の色がそろい、焼き込みテロップが見えない（または意図したデザインとして処理されている）
- [ ] テロップ・ラベルの書体、大きさ、位置、動きが規定どおりで、全編で一貫している
- [ ] 図解で「観測 → 位置が決まる」過程が、言葉と同期した動きで理解できる
- [ ] ナレーションが会場で聞き取れ、BGM・効果音・環境音・間が設計どおり
- [ ] 音楽が自然に終わり、ラウドネスが他パートと同じ基準
- [ ] 技術監修の確認済み（【要監修】ゼロ）
- [ ] 素材・ライセンス台帳が完全で、クレジットが必要なものは表記済み
- [ ] 納品物一式（マスター、ステム、台帳、変更履歴、再書き出しできるプロジェクト）がそろっている
- [ ] 「やってはいけないこと」（docs/04 §8）に一つも当たらない
